# CraftStudio

[English](README.md) | **简体中文**

一个在真实地形上设计 Minecraft 建筑的本地 3D 工作台。导入场地，在视口中绘制和建模，检查方块改动，再导出可以用于建造的蓝图。

CraftStudio 面向建筑审美与自由设计。辅助草图、建模工具、可复用构件、逐块编辑和 AI 自由建造可以在同一个工程里混合使用。

> 仓库默认展示英文 README；本页是完整中文版。目前应用界面以中文为主。

## 快速开始

### 离线 Lite：打开文件即可设计

1. 下载或克隆本仓库。
2. 用新版 Chrome 或 Edge 打开 [`lite/dist/CraftStudio-Lite.html`](lite/dist/CraftStudio-Lite.html)。
3. 导入自己的建筑或地形文件，也可以从空场景开始。
4. 保存便携工程以便继续编辑，或者导出 Minecraft 蓝图。

设计器包含在独立 HTML 中，不需要后端，也不需要启动 Minecraft。Lite 只读取你明确选择的文件，不扫描 Minecraft 安装目录。工程、版本、草稿和素材偏好保存在当前浏览器的 IndexedDB 中；换浏览器或电脑时，请使用便携工程或工程库备份转移数据。

### 本地版：SQLite 工程库与安装目录访问

Windows 下双击 `启动建筑工作台.cmd`。启动器需要已有的 Python 环境；可以通过 `CRAFTSTUDIO_PYTHON` 指定 Python 可执行文件。

也可以在仓库根目录启动服务：

```sh
python server.py --port 18767
```

打开 <http://127.0.0.1:18767/>。持续集成使用 Python 3.12，后端使用 Python 标准库。

通过 `CRAFTSTUDIO_MINECRAFT_HOME` 指定本地版使用的 `.minecraft` 目录。本地版增加 SQLite 工程库和所选安装目录的文件访问能力。进行设计时无需运行 Minecraft。

| | 离线 Lite | 本地版 |
|---|---|---|
| 3D 设计器与建模工具 | 共用设计器 | 共用设计器 |
| 输入来源 | 用户选择的文件 | 用户选择的文件及本地安装目录 |
| 工程保存 | 浏览器 IndexedDB | 本地 SQLite 工程库 |
| 便携工程与蓝图导出 | 支持 | 支持 |
| 是否需要后端 | 不需要 | Python 本地服务 |

## 设置基础资源库

打开**素材库 → 资源库**。本地版选择**从本地实例设置基础素材**，选定实例后导入默认勾选的原版和 Create 文件。Lite 首次选择自己的游戏／Mod JAR 或材质包 ZIP 即可。

资源库在本地版使用 SQLite、Lite 使用 IndexedDB 缓存资源资产，后续启动和新工程自动恢复已启用的文件。其他 Mod 和材质包按需加入，每项可启用、停用或上下移动；从上到下加载，后面的覆盖前面的。换用新的原版／Create 基础资源时，旧的同类基础资源会停用。工程库备份包含缓存资源，便携工程保留工程已使用的资产；公开安装包不包含游戏或 Mod 原始素材。

## 设计流程

1. **导入真实场地。** 把地形、河水和既有建筑作为起点，设计前检查坐标原点与选区。
2. **从预览中选择素材。** 按来源、形状、用途或色系筛选方块，也可以自建分类和收藏。
3. **绘制辅助几何。** 点击确定直线、曲线和闭合轮廓；连续折线用 Enter 或“完成开放路径”结束，点击起点或“闭合路径”闭合，并支持逐点撤销/重做。“精确坐标”中选中点后可插入后续线段中点或删除节点，适用于折线、多边形和贝塞尔控制点；先改预览，确认后沿用关联重建和一次撤销。固定点数图形继续调坐标，四点对称约束需先解除再改节点数量。已保存路径可驱动关联扫掠，闭合共面路径可直接拉伸；草图默认保存辅助线，不直接放置方块。贝塞尔控制点默认可沿 X／Y／Z 自由移动，主参数区提供可选的平面锁定。
4. **生成建筑形体。** 拉伸轮廓、连接多个截面放样，或沿路径生成。同一平面上首尾相接的独立线段可自动组成闭合截面，倾斜截面支持沿自身法线拉伸。闭合轮廓可沿自身平面向外或向内偏移，保留拐角与工作平面；结果是可复用的独立辅助轮廓。新建偏移记录来源与距离，可在草图列表“编辑来源”或“按来源重建”；源变化后标记待重建，显式预览/确认时一起更新下游结果，支持一次撤销并保留已支持的方块手改。“更换来源”可修复缺失参照，或从名称列表选择另一条已保存闭合轮廓；预览确认后一起更新偏移和下游结果，一次撤销恢复原来源及方块。自身/后代循环引用会拒绝。旧偏移缺少来源记录时继续保持独立。
5. **细化并对照。** 编辑方块、变换选区、复用构件，切换原始场地、完工方案和改动视图。
6. **确认并保存。** 生成结果先预览再提交；确认后的建模操作可一次撤销。保存可编辑工程，并导出所需蓝图。

界面采用固定工具列、中央 3D 视口、右侧场景集合与属性区，以及底部素材／构件架。建模面板停靠在视口外。拖动草图控制柄时立即反馈形状，后台计算精确的方块结果。

视口操作：**左键点击／拖动**选择或框选，**右键拖动**旋转视角，**中键拖动**平移，**F** 定位选择或场景。空格＋左键也可旋转视角。**Ctrl+Z／Ctrl+Y** 撤销与重做。绘制草图时，撤销/重做作用于取点；Backspace 或“退回上一点”撤回最近取点。Enter 先闭合多边形，再确认有效的轮廓或建模预览；控制点移动/坐标、草图尺寸和拉伸距离支持预览内撤销/重做；拖动中按 Esc 恢复起始状态并保留面板，窗口失焦也会取消这次拖动。改变其他操作设置会开始新的预览历史。尺寸与控制点可输入 `(12+4)/2`、`7/2` 等计算式，按 Enter 或离开输入框采用结果；未完成或无效的算式阻止确认，Esc 恢复原数值。目前工程保存计算后的数字，不保存参数方程。调整已完成草图时，X/Y/Z 限定控制点移动轴，Shift+轴键限定其余两轴平面，再按同一组合恢复自由。方向选择器显示世界轴或自定义锁定平面的 U/V 方向；工作平面锁定优先。文本框保留自身快捷键。放置每次只放一个方块。画笔可连续绘制空位，或涂改已有方块并保留已支持的形态／朝向。当前选择、表面、起笔取样材料、局部高度条件可组合并保存为预设，一笔可一次撤销。

## 已有能力

- **真实地形与改动记录：** 保留导入的原始场地，分别记录新增、替换和删除，保护地形、河水和保留区。
- **已保存草图重编辑：** 在场景集合选择草图，或双击辅助线重新编辑。确认时可更新关联的几何、拉伸、放样、扫掠结果，一次撤销同时恢复草图与方块。默认保留手改和手动删除；旧对象缺少归属快照或目标冲突会报告，可将生成对象独立化为方块对象。对象的来源详情提供“修复 / 更换建模来源”，从名称列表更换截面或扫掠路径，先预览再确认；对象/输出辅助线身份及下游引用保留，沿用手改保留和一次撤销。自绘截面扫掠同时追踪截面与路径；参数区按操作显示：拉伸距离、矩形扫掠截面宽高、放样/自绘截面扫掠的来源；空心开启后显示壁厚。此面板中，数字框 Enter 更新预览，视口 Enter 仅确认就绪结果，Esc 取消；焦点按钮保留 Enter 原生动作。空格保留表单控件操作，视口中仍可导航。需要已有生成归属记录。
- **草图与建模：** 直线、开放/闭合连续折线、贝塞尔曲线、矩形、圆、椭圆、圆弧、多边形、拉伸、放样、路径生成和贴地几何。存在合适方块变体时，曲线落格可以使用半砖和楼梯。贴地/挖填道路跳过水面、冲突建筑/植物和缺失地面，也检查加宽及斜线连接补格；挖填拒绝的列不会继续放道路方块。自动支撑先检查完整地面到设计面区间，阻挡时整根跳过，报告落地、阻挡、缺失、埋入地形和选区截断候选；这是方块几何候选，不是承载力仿真。自由高度设计仍可使用。
- **任意方向的平面截面：** 识别倾斜闭合轮廓，支持正向、反向、双向拉伸、空心与切除。不共面的轮廓会报错，不会强行压平；倾斜放样的截面目前需要相互平行。
- **组件定义与实例：** 关联实例共用已保存定义和固定放置变换，可从受支持的旋转／镜像实例更新定义，默认保留其他实例局部手改，支持扩大源范围或只为一份建立独立定义；普通复制保持独立。
- **隔离工作流：** 选定对象／区域后可隔离显示，状态条支持逐层退出并恢复相机与正交缩放。基础放置／画笔限制在邻近编辑范围内，隐藏对象成员不会被当空位覆盖；AI 明确编辑仍使用自身策略。
- **编辑与复用：** 方块状态、剪贴板、选区变换、镜像、阵列、对象分组和可复用构件。
- **素材库：** 按需生成预览、搜索筛选、收藏、别名、分层自建分类，以及同一方块归属多个分类。
- **Create 动态外观：** 已适配的旋转件和原生装置使用 Create 资源与保存数据展示。这是视觉支持，尚不具备完整产线仿真能力。
- **本地保存：** 可编辑便携工程、版本、草稿、工程库备份和素材偏好；本地版将完整设计器工程保存在 SQLite 中。
- **AI 设计接口：** 页面／Worker 公共接口支持精确读取场景、自由编辑方块、事务、冲突检查、保存导出和视口截图。AI 建筑不必套用预设房屋模板。

- **测量与视图：**间距、空间夹角、折线长度、草图吸附与收藏观察视角。
- **可复用工具设置：**可查找的画笔预设、绘制平面及 JSON 导入导出。

## 文件与资源

| 输入／输出 | 当前支持情况 |
|---|---|
| 原版／Create 结构 `.nbt` | 导入及 NBT 导出，保留已支持的原生数据与放置掩码 |
| Sponge `.schem` | 导入及导出，格式转换存在元数据限制 |
| Litematica `.litematic` | 导入，尚不能无损往返 Litematica 格式 |
| Anvil `.mca` | 从单个区域文件读取选定范围 |
| 材质包 ZIP 与 Mod／游戏 JAR | 从所选文件读取已支持的模型和贴图资源 |
| `.craftlite` | 可继续编辑的便携设计工程 |

资源文件可以按需补充。缺少资源时，部分方块会使用替代几何或材质，直到提供对应文件。尚不能通用适配所有 Mod 的自定义渲染器与行为。

Sponge 和 Litematica 转换不会完整保留所有实体、生物群系、计划刻和多区域信息。MCA 导入只读取一个文件内的选区，不转换实体、光照和计划刻。蓝图导出不等于完整 Minecraft 世界存档导出。

## AI 与游戏连接

共享页面／Worker 协议见 [设计接口说明](lite/DESIGN-API.md)：

```js
const result = await window.CraftStudio.request({
  schema: 'craftstudio-design/1',
  id: 'describe-workspace',
  method: 'workspace.describe',
  params: {}
});
```

此接口属于当前打开的设计器页面，不会自动暴露无需认证的 HTTP 写入口。外部 AI 仍需适配器及自己的工具调用循环；Python／MCP 兼容接口尚未与此协议完全统一。

可选的 [Java 游戏桥接](bridge/README.zh-CN.md)提供 **NeoForge 1.21.1、Forge 1.20.1、Fabric 1.20.1／1.21.1** 独立配置，各自生成对应 JAR；Fabric 还需 Fabric API。本地设计器选择**文件 → 连接 Java 游戏**，可以识别运行版本、读取区域、校验目标方块、施工改动、查看进度、停止和撤销。普通方块经过注册表校验后可跨 DataVersion 施工；原生实体及跨版本方块实体 NBT 仍需原生蓝图／转换流程。

单机写入需要创造模式；专用服务器写入需要管理员明确启用，桥接仍只监听本机。编译验证和真实游戏内验证分别记录。构建产物、安装步骤及版本矩阵见桥接文档。基岩版不在项目范围内。

## 开发与构建

安装 Node.js 22.13 或更高版本，然后执行：

```sh
cd lite
npm install
npm test
npm run build
npm run check:sync
```

在仓库根目录运行后端检查：

```sh
python -m unittest discover -s tests -p "test_*.py"
```

两个版本共用 [`lite/src`](lite/src)。一次构建生成 `lite/dist/CraftStudio-Lite.html`、`web/lite.html` 和 `web/index.html`，同步检查确认三个页面逐字节一致。GitHub `main` 更新并通过检查后，Actions 会重新构建并提交过期的生成文件。这不会自动上传本机修改：本地改动仍需先提交并推送到 GitHub。

下载新版后，重新打开 Lite HTML，或重新启动本地启动器并刷新页面。

## 项目范围、数据与许可

CraftStudio 仍在开发中。目前的限制包括自定义渲染器支持不完整、倾斜放样需要平行截面，以及尚无完整工程仿真或自动配置外部 AI 的能力。

公开构建不包含私人存档、用户蓝图、材质包、截图或数据库。构建默认排除用户数据；`LITE_SOURCE_NBT` 和 `LITE_REFERENCE_HTML` 是个人构建的可选输入，不要发布包含私人数据的输出。本地生成的数据库与日志已纳入忽略规则。

第三方声明见 [THIRD-PARTY](lite/THIRD-PARTY.txt)，第三方代码保留原许可条款。公开发布不包含 Minecraft／Mod 原始游戏贴图。主项目代码目前**尚未单独声明开源许可证**；仓库公开不代表获得无限制复用授权。

接口说明：[设计 API](lite/DESIGN-API.md)。

后端开发可使用 [local-engine](local-engine/README.md) 的共享 Node 宿主、SQLite 检查点与逐笔落盘确认控制器；Python 服务和设计器可按下面的方式选择启用。

素材库新增“最近使用”，并记住已使用素材的完整状态；再次选择或拖入时保留朝向、半砖/楼梯上下层等属性。收藏、分类及状态记录保存在本地偏好和工程库备份中。素材详情的“保存形态”可给同一方块保存多个朝向/形状，选择后预览，可显式保存更新或删除；已知属性与当前资源不兼容时明确报错，不悄悄替换保存状态。

## 可选的后端编辑路径

本地服务可通过现有 Python 鉴权入口调用 Node 编辑引擎。这条路径暂时需要显式启用，完整资源下的性能仍在优化。需要已有 Node 22.13+ 及 `lite` 依赖，不自动安装运行时。

Windows 可双击 `启动本地计算版.cmd` 或 `启动浏览器计算版.cmd`，原启动器继续使用默认/环境设置。也可运行 `start.ps1 -Computation Local` 或 `Browser`。切换正在运行的模式前先保存正式工程版本：启动器在重启前会询问，直接回车保留当前服务。两种模式共享工程库，但恢复各自工作状态，切换后从库打开保存的版本。页脚显示实际计算方式；缺少本地依赖时明确回退，不自动安装。也可启动前设置 `CRAFTSTUDIO_ENGINE=1`；找不到 Node 时可用 `CRAFTSTUDIO_NODE` 指定可执行文件。服务启动成功才声明 `local-engine/1`，界面随后直接使用带私有令牌的回环后端接口，并恢复最后确认场景与撤销/重做。直连只允许启动器的明确本地来源；没有直连接口的客户端仍可使用 Python 代理。独立 Lite 继续使用浏览器 Worker 和 IndexedDB。设置 `CRAFTSTUDIO_ENGINE=0` 可禁用。

启用后端后，所选文件按 4 MiB 分片读取、校验和传输，并支持取消，避免浏览器整文件缓冲。后端解析仍会在内存中组装完整输入；独立 Lite 保留浏览器解析。远端路径延迟尚未完成优化。开发接口见 [local-engine](local-engine/README.md)。
