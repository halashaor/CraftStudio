# CraftStudio

[English](README.md) | **简体中文**

一个在真实地形上设计 Minecraft 建筑的本地 3D 工作台。导入场地，在视口中绘制和建模，检查方块改动，再导出可以用于建造的蓝图。

CraftStudio 面向建筑审美与自由设计。辅助草图、建模工具、可复用构件、逐块编辑和 AI 自由建造可以在同一个工程里混合使用。

> 仓库默认展示英文 README；本页是完整中文版。目前应用界面以中文为主。

## 快速开始

### 离线 Lite：打开文件即可设计

1. 下载或克隆本仓库。
2. 用新版 Chrome 或 Edge 打开 [`lite/dist/CraftStudio-Lite.html`](lite/dist/CraftStudio-Lite.html)。
3. 导入自己的建筑或地形文件，也可以从空场景开始。
4. 保存便携工程以便继续编辑，或者导出 Minecraft 蓝图。

设计器包含在独立 HTML 中，不需要后端，也不需要启动 Minecraft。Lite 只读取你明确选择的文件，不扫描 Minecraft 安装目录。工程、版本、草稿和素材偏好保存在当前浏览器的 IndexedDB 中；换浏览器或电脑时，请使用便携工程或工程库备份转移数据。

### 本地版：SQLite 工程库与安装目录访问

Windows 下双击 `启动建筑工作台.cmd`。启动器需要已有的 Python 环境；可以通过 `CRAFTSTUDIO_PYTHON` 指定 Python 可执行文件。

也可以在仓库根目录启动服务：

```sh
python server.py --port 18767
```

打开 <http://127.0.0.1:18767/>。持续集成使用 Python 3.12，后端使用 Python 标准库。

通过 `CRAFTSTUDIO_MINECRAFT_HOME` 指定本地版使用的 `.minecraft` 目录。本地版增加 SQLite 工程库和所选安装目录的文件访问能力。进行设计时无需运行 Minecraft。

| | 离线 Lite | 本地版 |
|---|---|---|
| 3D 设计器与建模工具 | 共用设计器 | 共用设计器 |
| 输入来源 | 用户选择的文件 | 用户选择的文件及本地安装目录 |
| 工程保存 | 浏览器 IndexedDB | 本地 SQLite 工程库 |
| 便携工程与蓝图导出 | 支持 | 支持 |
| 是否需要后端 | 不需要 | Python 本地服务 |

## 设置基础资源库

打开**素材库 → 资源库**。本地版选择**从本地实例设置基础素材**，选定实例后导入默认勾选的原版和 Create 文件。Lite 首次选择自己的游戏／Mod JAR 或材质包 ZIP 即可。

资源库在本地版使用 SQLite、Lite 使用 IndexedDB 缓存资源资产，后续启动和新工程自动恢复已启用的文件。其他 Mod 和材质包按需加入，每项可启用、停用或上下移动；从上到下加载，后面的覆盖前面的。换用新的原版／Create 基础资源时，旧的同类基础资源会停用。工程库备份包含缓存资源，便携工程保留工程已使用的资产；公开安装包不包含游戏或 Mod 原始素材。

## 设计流程

1. **导入真实场地。** 把地形、河水和既有建筑作为起点，设计前检查坐标原点与选区。
2. **从预览中选择素材。** 按来源、形状、用途或色系筛选方块，也可以自建分类和收藏。
3. **绘制辅助几何。** 点击确定直线、曲线和闭合轮廓；草图默认保存辅助线，不直接放置方块。贝塞尔控制点默认可沿 X／Y／Z 自由移动，主参数区提供可选的平面锁定。
4. **生成建筑形体。** 拉伸轮廓、连接多个截面放样，或沿路径生成。同一平面上首尾相接的独立线段可自动组成闭合截面，倾斜截面支持沿自身法线拉伸。
5. **细化并对照。** 编辑方块、变换选区、复用构件，切换原始场地、完工方案和改动视图。
6. **确认并保存。** 生成结果先预览再提交；确认后的建模操作可一次撤销。保存可编辑工程，并导出所需蓝图。

界面采用固定工具列、中央 3D 视口、右侧场景集合与属性区，以及底部素材／构件架。建模面板停靠在视口外。拖动草图控制柄时立即反馈形状，后台计算精确的方块结果。

视口操作：**左键点击／拖动**选择或框选，**右键拖动**旋转视角，**中键拖动**平移，**F** 定位选择或场景。空格＋左键也可旋转视角。**Ctrl+Z／Ctrl+Y** 撤销与重做。放置每次只放一个方块。画笔可连续绘制空位，或涂改已有方块并保留已支持的形态／朝向。当前选择、表面、起笔取样材料、局部高度条件可组合并保存为预设，一笔可一次撤销。

## 已有能力

- **真实地形与改动记录：** 保留导入的原始场地，分别记录新增、替换和删除，保护地形、河水和保留区。
- **已保存草图重编辑：** 在场景集合选择草图，或双击辅助线重新编辑。确认时可更新关联的几何、拉伸、放样、扫掠结果，一次撤销同时恢复草图与方块。默认保留手改和手动删除；旧对象缺少归属快照或目标冲突会报告，可将生成对象独立化为方块对象。
- **草图与建模：** 直线、贝塞尔曲线、矩形、圆、椭圆、圆弧、多边形、拉伸、放样、路径生成和贴地几何。存在合适方块变体时，曲线落格可以使用半砖和楼梯。
- **任意方向的平面截面：** 识别倾斜闭合轮廓，支持正向、反向、双向拉伸、空心与切除。不共面的轮廓会报错，不会强行压平；倾斜放样的截面目前需要相互平行。
- **组件定义与实例：** 关联实例共用已保存定义和固定放置变换，可从受支持的旋转／镜像实例更新定义，默认保留其他实例局部手改，支持扩大源范围或只为一份建立独立定义；普通复制保持独立。
- **隔离工作流：** 选定对象／区域后可隔离显示，状态条支持逐层退出并恢复相机与正交缩放。基础放置／画笔限制在邻近编辑范围内，隐藏对象成员不会被当空位覆盖；AI 明确编辑仍使用自身策略。
- **编辑与复用：** 方块状态、剪贴板、选区变换、镜像、阵列、对象分组和可复用构件。
- **素材库：** 按需生成预览、搜索筛选、收藏、别名、分层自建分类，以及同一方块归属多个分类。
- **Create 动态外观：** 已适配的旋转件和原生装置使用 Create 资源与保存数据展示。这是视觉支持，尚不具备完整产线仿真能力。
- **本地保存：** 可编辑便携工程、版本、草稿、工程库备份和素材偏好；本地版将完整设计器工程保存在 SQLite 中。
- **AI 设计接口：** 页面／Worker 公共接口支持精确读取场景、自由编辑方块、事务、冲突检查、保存导出和视口截图。AI 建筑不必套用预设房屋模板。

## 文件与资源

| 输入／输出 | 当前支持情况 |
|---|---|
| 原版／Create 结构 `.nbt` | 导入及 NBT 导出，保留已支持的原生数据与放置掩码 |
| Sponge `.schem` | 导入及导出，格式转换存在元数据限制 |
| Litematica `.litematic` | 导入，尚不能无损往返 Litematica 格式 |
| Anvil `.mca` | 从单个区域文件读取选定范围 |
| 材质包 ZIP 与 Mod／游戏 JAR | 从所选文件读取已支持的模型和贴图资源 |
| `.craftlite` | 可继续编辑的便携设计工程 |

资源文件可以按需补充。缺少资源时，部分方块会使用替代几何或材质，直到提供对应文件。尚不能通用适配所有 Mod 的自定义渲染器与行为。

Sponge 和 Litematica 转换不会完整保留所有实体、生物群系、计划刻和多区域信息。MCA 导入只读取一个文件内的选区，不转换实体、光照和计划刻。蓝图导出不等于完整 Minecraft 世界存档导出。

## AI 与游戏连接

共享页面／Worker 协议见 [设计接口说明](lite/DESIGN-API.md)：

```js
const result = await window.CraftStudio.request({
  schema: 'craftstudio-design/1',
  id: 'describe-workspace',
  method: 'workspace.describe',
  params: {}
});
```

此接口属于当前打开的设计器页面，不会自动暴露无需认证的 HTTP 写入口。外部 AI 仍需适配器及自己的工具调用循环；Python／MCP 兼容接口尚未与此协议完全统一。

可选的 [Java 游戏桥接](bridge/README.zh-CN.md)提供 **NeoForge 1.21.1、Forge 1.20.1、Fabric 1.20.1／1.21.1** 独立配置，各自生成对应 JAR；Fabric 还需 Fabric API。本地设计器选择**文件 → 连接 Java 游戏**，可以识别运行版本、读取区域、校验目标方块、施工改动、查看进度、停止和撤销。普通方块经过注册表校验后可跨 DataVersion 施工；原生实体及跨版本方块实体 NBT 仍需原生蓝图／转换流程。

单机写入需要创造模式；专用服务器写入需要管理员明确启用，桥接仍只监听本机。编译验证和真实游戏内验证分别记录。构建产物、安装步骤及版本矩阵见桥接文档。基岩版不在项目范围内。

## 开发与构建

安装 Node.js 22 或更高版本，然后执行：

```sh
cd lite
npm install
npm test
npm run build
npm run check:sync
```

在仓库根目录运行后端检查：

```sh
python -m unittest discover -s tests -p "test_*.py"
```

两个版本共用 [`lite/src`](lite/src)。一次构建生成 `lite/dist/CraftStudio-Lite.html`、`web/lite.html` 和 `web/index.html`，同步检查确认三个页面逐字节一致。GitHub `main` 更新并通过检查后，Actions 会重新构建并提交过期的生成文件。这不会自动上传本机修改：本地改动仍需先提交并推送到 GitHub。

下载新版后，重新打开 Lite HTML，或重新启动本地启动器并刷新页面。

## 项目范围、数据与许可

CraftStudio 仍在开发中。目前的限制包括自定义渲染器支持不完整、倾斜放样需要平行截面，以及尚无完整工程仿真或自动配置外部 AI 的能力。

公开构建不包含私人存档、用户蓝图、材质包、截图或数据库。构建默认排除用户数据；`LITE_SOURCE_NBT` 和 `LITE_REFERENCE_HTML` 是个人构建的可选输入，不要发布包含私人数据的输出。本地生成的数据库与日志已纳入忽略规则。

第三方声明见 [THIRD-PARTY](lite/THIRD-PARTY.txt)，第三方代码保留原许可条款。公开发布不包含 Minecraft／Mod 原始游戏贴图。主项目代码目前**尚未单独声明开源许可证**；仓库公开不代表获得无限制复用授权。

更多资料：[架构说明](ARCHITECTURE.md)、[交互设计与实现状态](docs/interaction-spec.html)、[设计接口说明](lite/DESIGN-API.md)。

## 持续设计路线图

[设计路线图与研究记录](docs/design-roadmap.html)包含当前证据、参考工具、实施顺序和完整任务验收。文档研究、原型、编译检查和真实环境验证分别记录。目标是基于真实地形的自由人类／AI 建筑设计，本地版与 Lite 各有侧重。

大场景（原始与新增方块合计达到 10 万）按相机视野请求区块几何，并卸载视野外几何。完整方块数据仍可编辑、保存和导出；当前实现是几何按需加载，本地后端数据流式读取仍待实现。资源模型使用保守包围范围，相机请求合并，视口几何载入期间暂缓编辑。详情见[设计证据](docs/design-roadmap.json)。运行 `node lite/tests/performance-baseline.mjs` 可复现合成场景计算与缓冲数据量基准；它不测鼠标到可见反馈延迟或用户显卡帧率。

选区支持重新选择、增加、减去和交集。点击方块、对象或框选时，Shift 增加、Ctrl 减去；属性栏也可明确选择模式。对象的精确成员和区域体积共用笔刷、剪贴板、变换、删除与构件提取规则。黄色表示外接范围，蓝/红/紫表示增加、扣除和交集条件；选区变化不改动方块。见[选区验证记录](docs/validation/selection-combine.json)。

路径/图形与地形工具可使用通用选区的三维范围或 XZ 地面投影。投影模式先投影每个区域再组合，忽略 Y；三维模式逐格限制高度，包括支撑和挖填。辅助轮廓仍保持完整形状。本次范围取自选区，可明确重新获取；保存的路径参数保留范围。目标地面层可直接点击已有静态方块取样。预览报告固定在确认按钮上方。见[范围验证记录](docs/validation/construction-scope.json)。

地形工具中点击“拖动绘制坡道”，按住起点静态方块并拖向终点。拖动时实时显示轻量坡面与高差、距离、坡度；松开校准方块预览，再确认挖填。起终点地面层可直接修改；Esc 恢复绘制前的参数。端点以外保持首尾标高，并遵守作用范围。参数仅显示当前模式需要的内容。坡道端点随地形参数保存在工程中，方块结果重开已验证；已保存地形参数的再次编辑入口仍待实现。见[坡道验证记录](docs/validation/terrain-slope.json)。

草图可选取模型实际表面或三个不共线位置建立工作平面，并直接正对平面绘制。界面明确显示自定义平面、网格和局部轴；吸附、图形生成和锁定控制柄共用同一参照，取消锁定仍可自由编辑三维控制点。自动拉伸遵循保存的法线方向，包括负向面。工程保存保留平面参数；动态对象关联仍待实现。见[工作平面验证记录](docs/validation/custom-workplane.json)。

草图面板可在本工程保存、使用、改名/更新和删除命名平面；平面数据共用版本检查、事务、撤销与工程保存。已有草图保留快照。曲线位置滑条按采样折线弧长定位，截面方向沿路径传递；黄色小框只预览，明确使用后再绘制。AI 可用 `workplanes.list`、`workplanes.put`、`workplanes.remove`、`workplanes.atCurve` 调用相同能力。自动参照关联仍待实现。见[平面库验证记录](docs/validation/plane-library.json)。

单轨扫掠现可使用一个自绘闭合截面（包括凹轮廓）沿采样三维路径生成。可保留绘制偏移或居中，选择空心、端盖或切除。轻量连续面与精确方块校准分开，辅助轮廓稀疏显示；拉伸、放样和扫掠均可使用统一作用范围。源曲线更新保留手改，并可一次撤销。旧工程和快速矩形扫掠继续兼容。非平面闭合接缝、自交修复、多截面变化及半砖/楼梯边界精细化仍待完善。见[扫掠验证记录](docs/validation/profile-sweep.json)。

截面扫掠现支持沿轨道布置多个截面，按位置排序、统一采样并匹配闭合起点与正反方向，再线性或平滑过渡。中间凸起纳入生成范围，空心端盖厚度跨细分路径计算。修改源截面可联动更新并保留手改。不同首尾形状的自动修复与半砖/楼梯边界精细化仍待完善。见[多截面验证记录](docs/validation/variable-sweep.json)。

闭合空间轨道扫掠现可分散累计转动，校正首尾截面方向，并允许关闭校正。可自动或手动匹配各截面起点，调整起点百分比和反向，橙点显示起点。连续预览与方块落格共用校正参照；该功能处理方向闭合，不自动修复不同首尾轮廓或自交。见[闭合扫掠验证记录](docs/validation/closed-sweep.json)。

截面扫掠可选择半格边界拟合：先合并所有片段的格内占据采样，再匹配方块、上下半砖和直楼梯的朝向/上下半部。变体来自明确指定或可用素材族，缺少或不能表达的边界会报告。仍可使用纯方块模式，切除按方块进行。闭合体实际采样现与显示共用校正参照。8 点拟合属于近似，请检查薄壁、空腔和转角。见[边界验证记录](docs/validation/voxel-fit.json)。

扫掠诊断现可标记相隔较远的轨道片段在方块中心采样中的重叠，提供红框与定位按钮。可选择合并体积或停止确认；AI 提交和源更新遵守相同限制，作用范围过滤诊断。这属于采样检查，并非精确连续自交求解或自动拓扑修复，可能漏掉薄边界或附近相交。见[重叠验证记录](docs/validation/sweep-overlap.json)。

完整本地服务现可通过 `window.CraftStudio.request` 使用 `scene.baselineManifest` 和 `scene.readBaselineChunks` 查询原始基线区块。SQLite 缓存 16³ 区块并保留完整便携基线、蒙版、元数据、实体及类型化 NBT；只返回请求记录，区分空记录与越界。查询客户端采用限量 LRU 缓存。这是基线读取底座：当前 Worker 编辑仍持有完整场景，增量权威、渲染/生成/导出流式处理仍待实现；Lite 保留文件式编辑。见[本地区块验证记录](docs/validation/local-chunks.json)。

完整本地服务现将 Worker 的版本检查点镜像为区块增量。`scene.chunkSnapshot` 同步元数据和增量，`scene.readStoredChunks` 读取原始基线加当前检查点改动，包含删除、新范围和类型化 NBT；结果锁定版本/摘要，查询缓存按变化区块失效。未变版本避免重复发送完整增量/设计。这仍是派生查询镜像：Worker 保留完整编辑权威，限量视口编辑、后端生成仍未完成；本地保存/下载工程及完整 NBT 已采用版本锁定的逐区块导出，压缩输出和资源仍缓存，见[检查点导出说明](docs/checkpoint-export.md)；便携工程仍是恢复格式。见[增量区块验证记录](docs/validation/workspace-chunks.json)。
