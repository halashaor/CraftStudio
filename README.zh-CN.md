# CraftStudio

[English](README.md) | **简体中文**

一个在真实地形上设计 Minecraft 建筑的本地 3D 工作台。导入场地，在视口中绘制和建模，检查方块改动，再导出可以用于建造的蓝图。

CraftStudio 面向建筑审美与自由设计。辅助草图、建模工具、可复用构件、逐块编辑和 AI 自由建造可以在同一个工程里混合使用。

## 快速开始

### 离线 Lite：打开文件即可设计

1. 下载或克隆本仓库。
2. 用新版 Chrome 或 Edge 打开 [`lite/dist/CraftStudio-Lite.html`](lite/dist/CraftStudio-Lite.html)。
3. **开始工程。** 导入真实场地／蓝图文件，或选择**文件 → 新建空白工程**从零设计。初始工作范围不会生成方块或假地形。
4. **绘制辅助几何。** 在视口中点击绘制直线、曲线或闭合轮廓，保存为可复用草图；按需要设置工作平面，在三维空间调整节点。
5. **生成建筑形体。** 选闭合共面草图拉伸、多个平行截面放样，或沿路径扫掠截面；检查实际方块预览后确认。

设计器包含在独立 HTML 中，不需要后端，也不需要启动 Minecraft。Lite 只读取你明确选择的文件，不扫描 Minecraft 安装目录。工程、版本、草稿和素材偏好保存在当前浏览器的 IndexedDB 中；换浏览器或电脑时，请使用便携工程或工程库备份转移数据。

### 本地版：SQLite 工程库与安装目录访问

Windows 下双击 `启动建筑工作台.cmd`。启动器需要已有的 Python 环境；可以通过 `CRAFTSTUDIO_PYTHON` 指定 Python 可执行文件。

也可以在仓库根目录启动服务：

```sh
python server.py --port 18767
```

打开 <http://127.0.0.1:18767/>。持续集成使用 Python 3.12，后端使用 Python 标准库。

通过 `CRAFTSTUDIO_MINECRAFT_HOME` 指定本地版使用的 `.minecraft` 目录。本地版增加 SQLite 工程库和所选安装目录的文件访问能力。进行设计时无需运行 Minecraft。

| | 离线 Lite | 本地版 |
|---|---|---|
| 3D 设计器与建模工具 | 共用设计器 | 共用设计器 |
| 输入来源 | 用户选择的文件 | 用户选择的文件及本地安装目录 |
| 工程保存 | 浏览器 IndexedDB | 本地 SQLite 工程库 |
| 便携工程与蓝图导出 | 支持 | 支持 |
| 是否需要后端 | 不需要 | Python 本地服务 |

## 设置基础资源库

资源面板与外部 AI 现在共用同一个可复用资源库。`CraftStudio.resources`（MCP `designer_call` 的 `resources` 操作）可查看不含归档字节的列表、添加明确提供的 JAR/ZIP 资源，并按资源 ID 调整启用、排序或移除。修改需传最新工程身份与版本。无效候选保留当前资源并恢复原保存列表；工程导出仍携带使用到的内置资源。

打开**素材库 → 资源库**。本地版选择**从本地实例设置基础素材**，选定实例后导入默认勾选的原版和 Create 文件。Lite 首次选择自己的游戏／Mod JAR 或材质包 ZIP 即可。

资源库在本地版使用 SQLite、Lite 使用 IndexedDB 缓存资源资产，后续启动和新工程自动恢复已启用的文件。其他 Mod 和材质包按需加入，每项可启用、停用或上下移动；从上到下加载，后面的覆盖前面的。换用新的原版／Create 基础资源时，旧的同类基础资源会停用。工程库备份包含缓存资源，便携工程保留工程已使用的资产；公开安装包不包含游戏或 Mod 原始素材。

## 设计流程

1. **导入真实场地。** 把地形、河水和既有建筑作为起点，设计前检查坐标原点与选区。
2. **从预览中选择素材。** 按来源、形状、用途或色系筛选方块，也可以自建分类和收藏。
3. **绘制辅助几何。** 点击确定直线、曲线和闭合轮廓；连续折线用 Enter 或“完成开放路径”结束，点击起点或“闭合路径”闭合，并支持逐点撤销/重做。“精确坐标”中选中点后可插入后续线段中点或删除节点，适用于折线、多边形和贝塞尔控制点；先改预览，确认后沿用关联重建和一次撤销。贝塞尔提供“增阶保持曲线形状”，保留当前采样数直到真正编辑控制点，预览撤销与便携工程保留该设置。固定点数图形继续调坐标，四点对称约束需先解除再改节点数量。已保存路径可驱动关联扫掠，闭合共面路径可直接拉伸；草图默认保存辅助线，不直接放置方块。贝塞尔控制点默认可沿 X／Y／Z 自由移动，主参数区提供可选的平面锁定。
4. **生成建筑形体。** 拉伸轮廓、连接多个截面放样，或沿路径生成。同一平面上首尾相接的独立线段可自动组成闭合截面，倾斜截面支持沿自身法线拉伸。闭合轮廓可沿自身平面向外或向内偏移，保留拐角与工作平面；结果是可复用的独立辅助轮廓。新建偏移记录来源与距离，可在草图列表“编辑来源”或“按来源重建”；源变化后标记待重建，显式预览/确认时一起更新下游结果，支持一次撤销并保留已支持的方块手改。“更换来源”可修复缺失参照，或从名称列表选择另一条已保存闭合轮廓；预览确认后一起更新偏移和下游结果，一次撤销恢复原来源及方块。自身/后代循环引用会拒绝。旧偏移缺少来源记录时继续保持独立。
5. **细化并对照。** 编辑方块、变换选区、复用构件，切换原始场地、完工方案和改动视图。
6. **确认并保存。** 生成结果先预览再提交；确认后的建模操作可一次撤销。保存可编辑工程，并导出所需蓝图。

界面采用固定工具列、中央 3D 视口、右侧场景集合与属性区，以及底部素材／构件架。建模面板停靠在视口外。拖动草图控制柄时立即反馈形状，后台计算精确的方块结果。



## 已有能力

- **真实地形与改动记录：** 保留导入的原始场地，分别记录新增、替换和删除，保护地形、河水和保留区。
- **已保存草图重编辑：** 在场景集合选择草图，或双击辅助线重新编辑。确认时可更新关联的几何、拉伸、放样、扫掠结果，一次撤销同时恢复草图与方块。默认保留手改和手动删除；旧对象缺少归属快照或目标冲突会报告，可将生成对象独立化为方块对象。对象的来源详情提供“修复 / 更换建模来源”，从名称列表更换截面或扫掠路径，先预览再确认；对象/输出辅助线身份及下游引用保留，沿用手改保留和一次撤销。自绘截面扫掠同时追踪截面与路径；参数区按操作显示：拉伸距离、矩形扫掠截面宽高、放样/自绘截面扫掠的来源；空心开启后显示壁厚。此面板中，数字框 Enter 更新预览，视口 Enter 仅确认就绪结果，Esc 取消；焦点按钮保留 Enter 原生动作。空格保留表单控件操作，视口中仍可导航。需要已有生成归属记录。
- **草图与建模：** 直线、开放/闭合连续折线、贝塞尔曲线、矩形、圆、椭圆、圆弧、多边形、拉伸、放样、路径生成和贴地几何。存在合适方块变体时，曲线落格可以使用半砖和楼梯。贴地/挖填道路跳过水面、冲突建筑/植物和缺失地面，也检查加宽及斜线连接补格；挖填拒绝的列不会继续放道路方块。自动支撑先检查完整地面到设计面区间，阻挡时整根跳过，报告落地、阻挡、缺失、埋入地形和选区截断候选；这是方块几何候选，不是承载力仿真。自由高度设计仍可使用。
- **任意方向的平面截面：** 识别倾斜闭合轮廓，支持正向、反向、双向拉伸、空心与切除。不共面的轮廓会报错，不会强行压平；倾斜放样的截面目前需要相互平行。
- **组件定义与实例：** 关联实例共用已保存定义和固定放置变换，可从受支持的旋转／镜像实例更新定义，默认保留其他实例局部手改，支持扩大源范围或只为一份建立独立定义；普通复制保持独立。
- **隔离工作流：** 选定对象／区域后可隔离显示，状态条支持逐层退出并恢复相机与正交缩放。基础放置／画笔限制在邻近编辑范围内，隐藏对象成员不会被当空位覆盖；AI 明确编辑仍使用自身策略。
- **编辑与复用：** 方块状态、剪贴板、选区变换、镜像、阵列、对象分组和可复用构件。
- **素材库：** 按需生成预览、搜索筛选、收藏、别名、分层自建分类，以及同一方块归属多个分类。
- **Create 动态外观：** 已适配的旋转件和原生装置使用 Create 资源与保存数据展示。这是视觉支持，尚不具备完整产线仿真能力。
- **本地保存：** 可编辑便携工程、版本、草稿、工程库备份和素材偏好；本地版将完整设计器工程保存在 SQLite 中。
- **AI 设计接口：** 页面／Worker 公共接口支持精确读取场景、自由编辑方块、事务、冲突检查、保存导出和视口截图。AI 建筑不必套用预设房屋模板。

- **测量与视图：**间距、空间夹角、折线长度、草图吸附与收藏观察视角。
- **可复用工具设置：**可查找的画笔预设、绘制平面及 JSON 导入导出。

## 文件与资源

选区 NBT/ZIP 可选择包含外接范围内的场景实体。方块仍按精确成员导出；实体位置与方块锚点随裁切重定位，内部带类型 NBT 保留。交付包会说明实体数量及无法定位而未加入局部蓝图的数据，完整工程仍保留源实体。这不等于新增实体渲染、编辑或完成游戏生成验证。

| 输入／输出 | 当前支持情况 |
|---|---|
| 原版／Create 结构 `.nbt` | 导入及 NBT 导出，保留已支持的原生数据与放置掩码 |
| Sponge `.schem` | 导入及导出，格式转换存在元数据限制 |
| Litematica `.litematic` | 导入，尚不能无损往返 Litematica 格式 |
| Anvil `.mca` | 从单个区域文件读取选定范围 |
| 材质包 ZIP 与 Mod／游戏 JAR | 从所选文件读取已支持的模型和贴图资源 |
| 施工交付 `.zip` | 蓝图、坐标、对应范围清单及可选完整工程；支持直接回读 |
| `.craftlite` | 可继续编辑的便携设计工程 |

资源文件可以按需补充。缺少资源时，部分方块会使用替代几何或材质，直到提供对应文件。尚不能通用适配所有 Mod 的自定义渲染器与行为。

Sponge 和 Litematica 转换不会完整保留所有实体、生物群系、计划刻和多区域信息。MCA 导入只读取一个文件内的选区，不转换实体、光照和计划刻。蓝图导出不等于完整 Minecraft 世界存档导出。

## 工作区与视角

打开任务时，工具组随之定位：编辑草图进入“草图”，拉伸和排列进入“建模”，地形处理进入“场地”，直接变换进入“编辑”。只浏览其他工具组会保留当前预览；打开另一项操作沿用原有确认／取消规则。工具组用于导航，不是独立工程。

草图列表提供**定位**，无需先进入编辑。建模预览活动时，**F**优先定位当前轮廓与预览，不受旧方块选区影响；否则定位方块选择或整个场景。工具面板的定位按钮共用预览范围，覆盖完整圆形及拉伸深度，保留投影、朝向和缩放设置，Home 返回上一视角。双击对象行仍定位该对象。视口选中对象会揭示对应列表行；进入草图编辑会揭示并标记来源行，仅在当前筛选藏住目标时清除筛选。关闭或暂存后清除编辑标记，继续编辑时恢复。这些导航不修改工程几何。

在视口中右键点击而不拖动，可打开聚焦、隔离和常用变换菜单；不可用动作会显示前置条件。上／下方向键、Home／End 和 Enter 可导航及执行可用项。Esc 先关闭菜单并返回视口，不取消后面的预览；点击外部输入框保留输入焦点。菜单作用于已有选择，不会自动选中右键位置的对象。

| 操作 | 视口快捷操作 |
|---|---|
| 选择／框选 | 左键点击／拖动 |
| 旋转视角／平移 | 右键拖动／中键拖动 |
| 定位当前建模预览、选择或场景 | F |
| 查找工具 | F3 |
| 上一／下一相机视图 | Home／End |
| 重命名单个选中对象 | F2 |
| 撤销／重做 | Ctrl+Z／Ctrl+Y |

拖动视口与属性栏的边界、场景树下方分隔条或素材架上沿可调整工作区。Esc 取消拖动，双击分隔条恢复随窗口变化的默认尺寸；分隔条获得焦点后可用方向键调整，Shift 按一像素微调。尺寸本地保存，再次打开恢复；缩小窗口会限制尺寸，给视口留出空间。布局调整不进入场景撤销，也不改变工程几何。

工作区按视口实际宽度适配，包括拉宽属性栏的情况。窄视口分开场景模式和导航组，必要时组内滚动，不再直接隐藏功能。地形／植被／原建筑开关和收藏视角持续可用；素材架、场景树尺寸计入实际工具栏及展开视角面板高度，保留可用画面和属性区。素材操作按钮排在预览下方，避免文字竖排。

大场地中拖动工作区分隔条时，继续绘制已驻留的几何，不反复请求视口区块；松手或取消后按最终视口统一更新。普通镜头导航仍正常更新区块可见范围。此改动减少重复加载，不代表通用帧率或内存保证。

选择对象或区域后，可在属性面板或 F3 搜索中使用“聚焦选择”，保留相机朝向、透视/正交模式和缩放。F3 也可查找隔离编辑、退出一层隔离及恢复全部场景。

视口箭头返回上一／下一相机视角，在视口操作时也可按 Home／End。旋转、平移和连续滚轮各记为一步，包含惯性尾段；明确视图切换保留投影、缩放、视场角及朝上方向。相机历史独立于场景撤销，仅当前会话有效，启动、切换工程及重新打开保存版本时清空；新导航分支清除前进历史。输入框和素材卡片保留原生 Home／End，不会切视角。相机历史不恢复剖切或其他显示开关。

F3“空间浏览”支持连续 WASD 按视线移动、Q/E 世界高度升降、Shift 加速。Enter 保留当前透视视角退出，Esc 恢复进入前的位置／投影／缩放；输入控件和模态框保留按键上下文，E 不会误触取材。选择编辑工具时在当前视角退出浏览。它是不带碰撞的空间观察，不是 Minecraft 玩家移动或施工通行仿真。

空间浏览中的右键拖动改为眼点固定的原地观察，不再绕近处目标移动相机；俯仰有角度边界，避免越过观察极点翻转，并支持自定义朝上方向。拖动中 Esc 会释放捕获并恢复进入前视角，退出浏览后仍使用普通轨道导航。

F3 搜索补齐近期绘图、素材和视角工具，可试“平滑路径”“薄梁”“半砖步道”“改名字”“配色方案”“保存选区材质”。绘图结果直接进入对应曲线／图形模式，精确矩形直接选择对应扫掠预设；打开配色或视角显示不取消当前草图。条件不足的结果仍显示，并说明前置条件。

## 素材与工程配色

素材库新增“最近使用”，并记住已使用素材的完整状态；再次选择或拖入时保留朝向、半砖/楼梯上下层等属性。收藏、分类及状态记录保存在本地偏好和工程库备份中。素材详情的“保存形态”可给同一方块保存多个朝向/形状，选择后预览，可显式保存更新或删除；已知属性与当前资源不兼容时明确报错，不悄悄替换保存状态。

为建模参数选材时，素材架显示具体目标（主体、半砖、楼梯、填方、轮廓或辅助屋顶）。可连续试换素材比较预览，始终作用于该参数。取消操作、收起素材架、切换工具或主动打开通用素材选择会清除目标，之后的通用选材作用于放置／画笔。参数选材本身不修改场景，确认操作后才生成方块。

素材卡片显示当前选择。方向键按实际排布浏览并预览，Home／End 定位本行首尾，Ctrl+Home／End 定位当前页首尾；Tab 离开卡片区，无需逐个经过所有卡片。双击使用当前方块形态：给参数选材时更新该参数并保留建模操作，通用选材时进入放置。

工程配色方案位于现有素材架并随工程保存：新建命名方案、加入当前预览的完整形态、选择已存形态，或移出条目／删除方案。楼梯朝向与半部、半砖层位和未知 Mod 属性保留。本机分类与资源库保持独立，方案不限制人或 AI 自由编辑。确认的方案修改支持撤销及本地／Lite 保存重读。
可导出 `.craftpalette.json` 并在另一个工程中复用。导入先显示名称和完整形态，明确确认后新建方案；同名冲突不会覆盖，可改名再确认。文件仅含状态元数据，不含工程身份或资源档案。当前会话中导入可一次撤销。

工程配色方案可一键“从当前选区收集”完整方块状态。半砖类型、楼梯朝向／上下半部／形状等属性分别保留，重复收集自动去重。只把素材样本加入选定方案，不替换场地方块，也不加入选区外的素材状态；方案改动支持撤销重做及便携导出。收集顺序扫描选中方块，只返回去重状态统计，不准备整批方块／NBT 副本，也不改变选区排序。

设计工具新增“选区换材质”（F3 可搜索），针对当前对象／区域预览替换，从素材库选择目标。默认保留形态和朝向；没有对应形态、含方块实体数据的位置保留，并显示数量与原因。可用时在视口显示目标贴图／颜色，确认后一次撤销，取消不改变方块。既有建筑／地形保护规则继续生效，零替换预览不能假确认。

选区换材质列出当前选择实际使用的来源方块素材及数量。可保持“所有选中材质”，或只选一种来源替换；未匹配部分单独计数并保持原样。来源选择支持预览撤销重做，新开操作时重置。来源按方块类型区分，同一色系的半砖和楼梯可分别处理。

## 草图与形体生成

草图取点或拖动已有节点时，辅助线吸附也可寻找真实三维交点，并标明两条来源。拖动按节点的投影位置使用与绘制相同的屏幕距离，先排除当前操作柄轴／平面及工作平面锁定无法到达的目标；吸附来源轮廓会高亮为青色，交点同时高亮两条来源，移开或暂停后恢复原色；隐藏辅助线也会暂停轮廓吸附。按住 Ctrl 临时暂停吸附，完成一次拖动可一次预览撤销。吸到的精确坐标可以保存，不会再次强制舍入半格。隐藏草图、正在编辑的草图及锁定工作平面以外的交点不作为候选。曲线按已保存的采样折线计算，尚不是解析曲线求交、延长线吸附或屏幕投影交点；共线重叠不生成唯一交点目标。提示标记仅供视口显示，已取点保存为坐标，不是会随来源自动移动的交点约束。

导入自己的建筑或地形文件，也可以从空场景开始。

保存便携工程以便继续编辑，或者导出 Minecraft 蓝图。

草图控制点随缩放保持易辨认的屏幕尺寸，当前节点更大，并与坐标行高亮同步。贝塞尔编辑显示控制多边形，区分控制点连线与实际曲线；这些是视口辅助显示，不额外导出为方块或草图。原有三维轴／平面约束、预览历史和关联重建仍可使用。

在草图中选择“贯穿点曲线”，连续点击曲线应经过的位置。Enter 完成开放路径，“闭合路径”或点击起点可闭合。它与现有单条贝塞尔曲线并列，支持更长的途经点序列，修改只影响邻近段；节点可三维编辑，复用预览、撤销和素材流程。可以只保存辅助轮廓，也可在确认前生成方块；保存的平面闭合曲线可用作拉伸轮廓，自动落格可产生半砖／楼梯。底座采用向心三次插值，不是 NURBS 或完整切线约束编辑器。

自定义工作平面的轮廓／填充和直接落格偏移已修复轴向平面查表异常，加宽仍沿绘制平面处理，沿用表面高度落格。轮廓素材标签初次打开就显示真实默认素材，素材选择参与预览撤销／重做。

编辑辅助轮廓时，可直接进入拉伸或沿路径生成。未改变的已保存轮廓直接打开建模，不增加空编辑；新增或修改的轮廓先确认，再打开未提交的实体预览。取消实体预览会保留已确认来源，来源和实体分别可撤销。已保存的辅助轮廓固定“仅辅助”状态，避免误以为切换该框就能直接新增实体；开放／非平面轮廓的拉伸入口禁用并说明原因。面板内路径入口先使用可调整或切换的简单矩形截面。

路径生成新增“精确矩形”：宽高支持半格，沿路径法向截面扫掠，并显示自动方块／半砖／楼梯落格及素材角色。宽度以路径居中，高度沿截面上方向延伸，空间路径可能使截面倾斜。原“快速矩形”仍保持竖直整方块行为。已有生成方块的草图重新编辑时保留几何模式，不再误判为纯辅助来源。

构造工具的“定位”会保留当前朝向、投影与缩放，显示轮廓和可用预览范围，并正确包含对称拉伸两侧；工具及当前参数保持打开。

场景列表可筛选“需要处理”的生成对象：已记录的草图来源缺失显示错误，明确标记待更新的结果显示提醒。对象标记说明原因，原有来源详情提供编辑／修复操作。检查不改方块、不锁住无关编辑，已独立化对象不纳入。当前状态针对已记录的来源关系，不代表所有生成失败都已诊断。

生成诊断也会沿已记录的对象输出辅助线传播：下游显示受影响的上游名称，实际循环成员单独标记，并报告输出归属冲突。独立化输出截断传播，来源详情显示具体原因。这些检查针对已记录关系和待更新标记，不替代几何生成校验。

生成对象也会报告偏移轮廓祖先来源的失效、循环或待重建。按名称修复偏移来源并确认后清除问题；取消保留原状，撤销恢复旧来源。上一级偏移待重建显示提醒，不误报成来源缺失。

## 适应真实地形

贴地几何预览按缺少地面数据、水面、既有障碍分类显示略过的候选列。“定位未生成处”会显示并聚焦诊断标记：黄为缺数据，蓝为水面，红为障碍；缺地面标记的高度来自设计路径，不推断原地形标高。诊断遵循所选平面范围，重新编辑已保存路径也保留反馈，不改原地形，也不在略过列放置方块。

新建贴地放置的全部候选列被略过时，界面不再提供误导性的放置确认；可调整路径／地形方式，或主动选择仅保存辅助轮廓。仅轮廓确认会明确提示未放置方块。部分有效路线、已保存来源编辑保留原流程；这是界面引导，不限制自由几何及 API 底座。

地形数值预览历史已覆盖整平标高、平滑半径、坡度与端点高度；端点及其派生坡度一起恢复。确认前不改原地形，确认后仍用场景撤销。普通数值的有效预览可直接确认，无需因失焦重复重算再点一次。

## 选区、变换与构件

场景浏览器在折叠筛选中支持对象类型及可见／隐藏／锁定状态。“选中筛选结果”只选可见的匹配对象；Shift 增加、Ctrl 减去。隐藏结果仍可列出检查，但不加入这项选择；可见的锁定对象可选中查看，几何保护保持。集合选择明确为“选择可见成员”，整个集合隐藏时禁用。过滤列表不隐藏模型，也不修改工程或修订。

选择命名对象后按 **Ctrl+F2**，可在固定检查器中批量命名；多选时 **F2** 也会打开批量预览，单个对象仍原位编辑。模板支持 `{name}`、`{n}`、起始编号、补零、创建／名称／XYZ 顺序及可选的原文字面替换。确认前显示原名与新名；输入框 Enter 确认、Esc 取消。每批可一次撤销，只改名称。共用 `objects.rename` 接口只需对象 ID／名称列表，不必重发几何。

场景侧栏的“常用选择”可保存、更新、恢复或移除选择记录。对象引用随对象移动；复制出来的对象身份独立，不自动加入。恢复时略过隐藏或失效对象并显示数量，可见的锁定对象仍可检查。自由方块选区保留精确的固定坐标。记录随可编辑工程保存、支持撤销，不导出为 Minecraft 方块；移除记录保留模型。

**构件库**入口直接打开固定素材架，不再进入创建面板。当前工程构件可按名称、自建分类或尺寸搜索，按分类筛选，按最近加入或名称排序。选择条目只查看详情，按“三维预览并放置”或拖入场景才开始放置；导入与从选择创建是独立按钮。详情中可编辑名称和分类，随工程及构件 JSON 保存，信息修改可单独撤销。“打开本地构件库”会筛选已保存的构件。

可复用构件 JSON 同时支持显式方块状态和调色板索引。导入与放置共用读取模块，无效索引或坐标会在写入场景前报错，合法的其他 Mod 方块 ID 和带类型数据仍支持。修正文件后可再次选择同名文件，构件定义与已放置方块随工程保存、回读。

确认移动、复制或 90° 旋转后，按 **Shift+R** 可对当前选择预览同样的变换。“更多变换”、右键菜单及命令搜索中也有“重复上次变换 · 预览”。确认后执行，取消不改场景，每次确认可单独撤销。重复使用当前几何，保留上次按世界轴计算的外接范围位移与四分之一圈转向，不重放缓存的旧构件。切换工程会清除记忆，工程文件不保存此操作状态；此快捷入口不包含粘贴、换材质和建模生成。

粘贴确认后的选区来自实际改动，排除重叠策略跳过的原有方块、保护跳过和无需修改的相同方块，继续移动不会带走跳过的原物。撤销历史达到 30 条时，粘贴和建模确认仍可一次撤销。变换提交后先标记草稿并更新选区，再刷新视图，避免显示失败时把已提交修改误当成可重试预览。

场景浏览区统一搜索对象和可编辑草图。输入建筑、集合、组件定义或上游草图名称，可以找到相关建筑及来源轮廓，包括偏移轮廓的上游来源。集合和“只看需要处理”同时筛选两份列表；数量反馈和“显示全部”明确当前范围。筛选不隐藏或修改场景方块；打开其他工程会清除旧筛选。常用浏览控件位于搜索框下方，新建、归入、改名、锁定等操作收在“管理集合”。默认场景树高度随面板可用高度分配，已保存的自定义布局优先。

在**管理集合 → 锁定集合**中，可一起保护集合成员方块。手工编辑、AI 编辑、粘贴预览、关联组件更新和草图重建共用保护规则；锁定后仍可选择、查看和导出。保护遵循对象的精确成员，外接框内无关的内部方块仍可编辑；没有成员记录的旧对象保留范围保护。解锁集合保留各对象原来的独立锁定。锁定变更可撤销／重做，并随本地或便携工程保存、回读。

在选择属性区切换“方块”（默认）或“对象优先”。对象优先按点击格的实际成员选中命名对象，未归属对象的格仍按单方块处理；重叠时优先较小对象，已有候选被选中时保持它，Alt+点击循环切换。Shift 增加、Ctrl 减去沿用精确选区规则，隐藏对象及隐藏集合不会作为候选。点击只改变选择，移动／复制／旋转仍需另行预览确认。该偏好仅保留在当前页面，切换的是命中格的所属对象，不会穿透不相关的遮挡几何。

框选命名对象时，左向右拖显示蓝色实线框，要求完整框入；右向左拖显示绿色虚线框，相交即可选入。拖动时同时标明方向及重新选择／增加／减去／交集。Esc 取消本次框选并保留原选择，继续移动尚未松开的鼠标不会重新开始。对象判定目前按投影外接框，不是精确可见表面或遮挡过滤。

对象列表的增加／减选和对象框选会保持名称高亮与精确方块选区一致，全部减去后清空选择。重叠对象仅剩部分方块时使用自由区域路径，避免误复制整个对象；完整多对象选择仍可用于对齐／分布。

切换工程工作区会清空选择、坐标输入和已展开来源详情，即使新工程复用对象 ID 也不继承旧选择。撤销分组会移除失效名称引用，但保留有效自由方块选区；同工程隐藏／保存保留选择。没有活动选择时，不再仅因旧坐标范围仍较大就显示已选区域。

选中一个对象后，可按 F2、点击属性区“重命名”或使用视口右键菜单。在对象树中直接输入：Enter 确认，Esc 取消，离开输入框采用有效的新名称；空名称保留原名。改名保留对象身份、几何及组件记录，可一次场景撤销，且不会改动共享组件定义的名称。素材卡片和文本控件中的 F2 不会穿透到场景。隔离或 Create 显示变化后，对象选择及命名入口仍可使用。

直接移动／复制／粘贴的位移框支持计算式和拖动标签。输入框 Enter 更新预览，Esc 恢复该输入；焦点按钮的 Enter 保留自身动作，包括取消按钮。视口 Enter 才确认。无效或未完成表达式不能确认，变换确认后仍可一次撤销。
直接操作柄拖动中断后会释放拖动状态与指针捕获。拖动中按 Esc、窗口失焦、指针取消或捕获丢失时恢复本次拖动起点，并保留操作预览供继续；未在拖动时按 Esc 取消整个操作。正常松开鼠标保留调整后的预览。

直接移动／复制／旋转／粘贴预览中，撤销／重做逐步恢复已完成的预览调整，不再整体取消。数值编辑、操作柄拖动、转 90°、粘贴位置锁定与重叠设置分别计步，新修改清除旧重做分支。确认前不改已确认方块，确认后仍是一次场景撤销。预览历史仅保留于当前操作会话。

直接变换准备时立即在固定属性区显示状态，尚不可用的控件禁用。Esc 或取消可放弃准备，迟到回复不会重新打开或提前启用新的请求；复制未完成时等待粘贴也遵守此规则。场景变化使准备失效，预览与复制读取校验版本和工程身份。界面取消不等于抢占中断已运行的 Worker 计算。

直线阵列和关联实例新增“留空隙排列”，原来的自由 XYZ 位移保留。按所选构件占格跨度加空隙计算步距，支持反向，确认前显示实际整格间距；半砖 / 楼梯按占格边界计算，不代表精确模型表面间距。

沿路径阵列可选择固定间距，或按指定数量均分整条路径。开放路径包含首尾；闭合轮廓补齐闭合边且不重复首尾。预览显示实际数量与理论间距，落格后重复的锚点会明确跳过。

对象集合可按建筑或区域整理方块对象。在场景集合面板中新建命名集合、归入选中对象、筛选成员、选择全部成员或整体隐藏／显示。解除集合只清除归类，不删除方块；成员自己的隐藏状态独立保留。已确认的集合修改支持撤销和工程保存重读。目前为单层集合，每个对象归入一个集合。
可将选中成员单独移出集合；对象行显示当前所属集合。移出保留方块并支持撤销。

隔离时可勾选“显示周围参照”，查看地形和其他可见内容，不退出当前层，也不扩大局部画笔范围。嵌套各层保留自己的参照显示状态，退出一层恢复上一层与相机；显式隐藏的对象仍保持隐藏。隔离是显示及局部画笔辅助，不是全局写入权限，通用人工／AI 编辑接口仍可自由使用。范围外单方块放置会在开始操作前提示，避免空操作。

选中关联实例后，属性区显示同类数量、隐藏／锁定状态和实例列表。可选择未隐藏的同类一起操作，或从列表选一份作为“更新同类”的来源。确认预览显示来源及包含隐藏实例的联动数量。“只改这一份”建立独立定义；同类中有锁定实例时，先检查锁定再更新。隐藏实例不会被自动显示。相关动作集中在属性区，不再重复占据每个对象树行。

移动／复制／粘贴操作柄默认使用世界坐标，转过 90° 后仍与世界位移 ΔX／ΔY／ΔZ 一致。需要沿旋转后的构件方向拖动时，在“操作柄参照”选择“随预览旋转”；数值框仍表示世界位移。切换参照保留当前位置，支持预览撤销／重做；新操作默认恢复世界坐标。这里跟随当前预览的旋转，不是组件定义中保存的局部坐标系。

## 预览、数值输入与键盘焦点

视口操作：**左键点击／拖动**选择或框选，**右键拖动**旋转视角，**中键拖动**平移，**F** 定位选择或场景。空格＋左键也可旋转视角。**Ctrl+Z／Ctrl+Y** 撤销与重做。绘制草图时，撤销/重做作用于取点；Backspace 或“退回上一点”撤回最近取点。Enter 先闭合多边形，再确认有效的轮廓或建模预览；控制点移动/坐标、草图尺寸和拉伸距离支持预览内撤销/重做；拖动中按 Esc 恢复起始状态并保留面板，窗口失焦也会取消这次拖动。切换工具类型、工作平面或取点来源会开始新的预览历史；已支持的参数调整可在预览中撤销。尺寸与控制点可输入 `(12+4)/2`、`7/2` 等计算式，按 Enter 或离开输入框采用结果；未完成或无效的算式阻止确认，Esc 恢复原数值。目前工程保存计算后的数字，不保存参数方程。调整已完成草图时，X/Y/Z 限定控制点移动轴，Shift+轴键限定其余两轴平面，再按同一组合恢复自由。方向选择器显示世界轴或自定义锁定平面的 U/V 方向；工作平面锁定优先。文本框保留自身快捷键。放置每次只放一个方块。画笔可连续绘制空位，或涂改已有方块并保留已支持的形态／朝向。当前选择、表面、起笔取样材料、局部高度条件可组合并保存为预设，一笔可一次撤销。

草图 / 建模数值框可拖动标签或按 Alt 拖动数值；Shift 微调，Ctrl 按该字段步长吸附，Esc 取消这次拖动。拖动只调整预览，放置方块仍需确认；控制点 / 深度继续支持预览撤销。

构造确认前，草图 / 建模数值参数（含扫掠宽高、空心壁厚）支持局部预览撤销 / 重做。在视口按 Ctrl+Z / Ctrl+Y，可回退参数而不撤销已保存场景；切换工具或来源选择会重置这段临时历史。

构造预览历史也覆盖常用草图 / 建模勾选项和选项列表，包括填充、空心 / 端面与落格方式。切换工具类型、工作平面或来源选择仍会重置这段临时历史。

排列与建模参数的数值框复用草图／直接变换的计算式和标签拖动。Enter 或离开输入框采用计算结果并更新预览，Esc 恢复该输入。当前可见的未完成／无效表达式阻止确认，不改变场景；生成器原有整数、范围及来源校验仍适用。

排列／建模参数预览支持本地撤销／重做。完成的数值、选项、来源选择和素材修改可逐步退回而不关闭工具；错误表达式先恢复。新修改清除旧重做分支，切换操作或场景变化重置参数历史；确认结果仍可一次场景撤销。历史仅保留于当前操作会话。

测量与草图共用端点、中点、中心和真实交点吸附，以及来源高亮、Ctrl 暂停和隐藏辅助线过滤。已吸附的小数坐标会保存在标注中，标注仍是位置快照。相邻曲线采样接缝和闭合接缝不作为交点，非相邻线段的真实自交仍可选。

测量预览支持取点、完成的坐标／名称编辑、退点和重新取点的本地撤销／重做。撤销保留测量工具，恢复重新取点前的已有标注身份。保存标注前不改方块或已保存标注；保存后仍可一次场景撤销。历史仅当前会话，切换测量类型重新开始取点。

测量坐标也可输入 `(5+1)/4` 等计算式，Enter 采用结果；拖动轴标签或 Alt+拖动数值实时调整预览，Shift 微调，Ctrl 按半格吸附。每次完成输入或结束拖动分别计为一步预览撤销。空值、无效或未完成计算式会禁用保存标注；Esc 或预览撤销先恢复输入，保留小数坐标精度。

原生模态窗口优先接收键盘输入：Esc 关闭窗口而不取消后面的预览，Enter 保留焦点窗口按钮的动作，撤销不会改变下面的变换。关闭窗口后恢复视口快捷键；固定设计面板仍沿用原有工具规则。

设计面板中，焦点按钮、复选框、选择框等控件的 Enter 保留控件动作，不会确认后面的操作。点击视口会明确聚焦画布，即使工具捕获指针，仍可用视口 Enter 完成绘制或确认。规则统一覆盖构造、排列、直接变换和测量。

素材卡片或面板控件获得焦点时，场景工具字母键、删除和场景复制粘贴不会穿透操作。对象名称选择按钮仍属于场景快捷键上下文，选中后可直接按 M／C／R。点击视口后继续使用场景快捷键；Enter 和空格仍激活当前控件。保存、打开、素材搜索和预览撤销重做沿用原有上下文。

确认或取消操作使面板关闭时，原先在该面板内的焦点会返回视口，可立即继续使用场景快捷键。如果你正在其他可见控件中输入或浏览，关闭旧面板会保留当前焦点；直接切换面板时，失去目标的焦点转到新面板。

## 保存与继续设计

**交付建筑：**打开**保存 / 导出**，选择新增／替换、含拆除的全部变更、当前选择或完整场地，再下载施工交付 ZIP。包内包含 `blueprint.nbt`、放置坐标、对应范围的变更表、材料表和清单。完整场地的材料表只统计本次变更所需放置材料，不是原地形材料总量。勾选**附带完整工程**会加入完整设计和原始场地。CraftStudio 可直接打开 ZIP：有工程时恢复完整设计，否则按已确认的世界坐标读取蓝图；未知坐标保持未确认。打包检查同一个场景版本，拒绝混合版本；附带工程的名称不改动当前设计名称。单独的 NBT、工程、CSV 和 Sponge 导出保留在**单独导出文件**中。文件回读不等同于实际游戏施工验收。

**单独导出建筑：**选择对象或方块区域，再用**保存 / 导出 → 单独导出文件 → 仅当前选择 NBT**。导出遵循对象的精确成员和组合选区，外接框里的无关方块不会混入。保留楼梯、半砖等方块状态与类型化方块实体 NBT；附带 JSON 说明局部偏移及已确认的世界放置坐标。选区 NBT 不包含场景实体；需要完整场景时使用完整工程／完整场地导出。变更蓝图与游戏施工准备共用边界和调色板处理，支持大批量改动及明确的拆除空气，导出不会修改当前工程。

只有草图、尚未生成方块的设计也能独立保存。切换场景前会将已确认内容保留到本地工程库，包括辅助草图；如果保存失败，会保留当前场景，便于重试或导出便携工程。

构造工具可在当前工程会话内“暂存”未确认操作，随后从固定属性区“继续”，恢复控制点、范围、素材、参数和预览历史，并按当前场景重新校准。每类工具保留最近一份；明确关闭 / Esc 放弃当前操作，切换工具可保留。更换工程清空会话暂存。明确点击“暂存”并等到显示已保存在本地，会同时保存工程草稿和未确认设置；刷新后内容匹配时可继续。切换工具保留的会话状态仍需明确暂存才能跨刷新；已确认内容改变时不自动匹配旧记录，完全相同的内容副本可能共享暂存槽。

本地浏览器计算和独立 Lite 的自动草稿现在保留已确认编辑的撤销／重做历史。历史保存改动区块版本和去重设计快照，不在每步复制原地形，恢复完整方块状态、方块实体 NBT 和元数据修改。旧草稿无历史也可读取；正式完整工程导出不附加撤销日志。

未确认工具预览中，快捷保存显示“保存已确认部分”，保存结果说明当前预览未写入工程。保存不自动采用或丢弃预览，在当前页面仍可继续调整；确认后再保存才包含该改动。已支持的构造工具仍可明确“暂存”，单独保存未确认意图。

本地版与 Lite 导出便携工程时，默认使用当前工程名称；接口明确传入导出名称时采用该名称。工程库的“打开”通常恢复最新草稿；查看正式保存版本时请选择编号的历史版本。

正式保存会在序列化前冻结名称、备注、标签、尺寸和方块统计，并校验场景版本。期间的新修改不会被误算入该版本；草稿保存成功时，结果说明这些修改保留在工作草稿中，需再次正式保存。保存期间新输入的备注不会被清空。

待提交的保存表单（名称、原始标签文本、类型、下一版本备注）随本地工作草稿恢复；可选本地引擎以工程工作区绑定的本地偏好恢复表单。已提交备注在写入下次草稿前清除，刷新后不会重复出现。打开其他工程重置其字段，正式建筑导出不包含待提交表单。

## 大场景与本地计算

浏览大场景时，视口网格、共享材质和贴图会释放不再使用的图形资源；返回后重新载入贴图。已缓存的 Create 模型会保留所需贴图，临时图片地址在解码后释放。完整方块数据仍驻留内存，这不等于全场地数据流式读取。

大场景现在分批显示附近区域，加载中仍可旋转视角；当前视野未载完时暂缓放置，失败后转动视角可重试。切换指定视角时清除残留旋转惯性。

本地服务可通过现有 Python 鉴权入口调用 Node 编辑引擎。这条路径暂时需要显式启用，完整资源下的性能仍在优化。需要已有 Node 22.13+ 及 `lite` 依赖，不自动安装运行时。

Windows 可双击 `启动本地计算版.cmd` 或 `启动浏览器计算版.cmd`，原启动器继续使用默认/环境设置。也可运行 `start.ps1 -Computation Local` 或 `Browser`。切换正在运行的模式前先保存正式工程版本：启动器在重启前会询问，直接回车保留当前服务。两种模式共享工程库，但恢复各自工作状态，切换后从库打开保存的版本。页脚显示实际计算方式；缺少本地依赖时明确回退，不自动安装。也可启动前设置 `CRAFTSTUDIO_ENGINE=1`；找不到 Node 时可用 `CRAFTSTUDIO_NODE` 指定可执行文件。服务启动成功才声明 `local-engine/1`，界面随后直接使用带私有令牌的回环后端接口，并恢复最后确认场景与撤销/重做。直连只允许启动器的明确本地来源；没有直连接口的客户端仍可使用 Python 代理。独立 Lite 继续使用浏览器 Worker 和 IndexedDB。设置 `CRAFTSTUDIO_ENGINE=0` 可禁用。

启用后端后，所选文件按 4 MiB 分片读取、校验和传输，并支持取消，避免浏览器整文件缓冲。后端解析仍会在内存中组装完整输入；独立 Lite 保留浏览器解析。远端路径延迟尚未完成优化。开发接口见 [local-engine](local-engine/README.md)。

可选本地计算引擎现在将原始方块按区域独立保存并校验，查询原始区域时不必载入无关数据块，并检查存储版本。旧检查点可恢复，下一次成功保存时升级。本地计算工作区按需解码原始区域，缓存数量有上限；数据库中的原始区块通过只读连接按需读取；内存测试工作区保留压缩区块。首次解析、全场地操作和完整导出仍可能临时载入全部数据。

## AI 与游戏连接

AI 可通过共用 v1 API 的 `prefabs.list/read/put/place/remove` 操作同一份当前工程构件库：读取摘要、分页读取方块、导入或从精确选区捕获、修改信息、放置及移除。沿用版本保护、事务、请求回执和撤销；暂存内容在提交前不出现在页面。构件复用是可选工具，AI 仍可自由编辑方块，不被限制为套模板。

外部 AI 现在可共用页面已经手动连接的 Java 游戏会话：`CraftStudio.game` 或 MCP 的 `game` 操作支持状态、准备、建造、进度、停止、回读及撤销。准备会返回编号并更新页面核对信息；建造必须传同一准备编号和当前工程、连接身份。游戏回读沿用页面导入与检查点流程，返回状态不暴露令牌。完整接入通过模拟桥接验证，真实 Minecraft 施工仍未验收。

游戏交付采用“准备并检查 → 核对 → 确认建造”的流程。核对信息包含来源版本、方块数、维度、实际世界范围及覆盖方式。除新增、全部改动和完整场景外，可交付当前选中的建筑或区域，保持对象精确成员及场地相对偏移。设计、选区或目标变化后需重新准备，确认只发送已检查的内容一次。本流程通过模拟桥接验证，尚未完成真实 Minecraft 施工验收。

### 外部 MCP 客户端接入可见页面

连接后的页面也支持外部 AI 打开明确提供的文件：调用 `designer_call`，设 `operation: "import"`，传入 `options: {name, dataBase64, workspaceId, expectedRevision}`；`.mca` 另需 `region: {min, max}`。先读取 `workspace.describe`。当前设计先保存检查点，文件在候选场景解析；解析失败或工程、版本冲突时保留当前场景，成功后返回新工程身份。此操作打开新场景，不会把文件合并到已有建筑。

启动本地工作台，在**AI 设计**中勾选**连接当前 3D 工作台**。MCP 客户端以 stdio 启动 `python /绝对路径/CraftStudio/mcp_server.py`。默认连接 `http://127.0.0.1:18767`；自定义端口使用 `CRAFTSTUDIO_URL`，不需要额外 Python 包。连接偏好随浏览器标签页保留；刷新后的 sessionId 会更新，应重新查询页面。

先调用 `designer_sessions`，再用 `designer_call` 的 `operation: "request"` 转发共用 Design API 请求。从 `workspace.describe` 开始；MCP 的版本请求必须同时带 `expectedRevision` 与 `workspaceId`。请求 ID 支持字符串或安全整数（含 0），同一 ID 只能重试相同内容。多个页面连接时指定 sessionId。读取、自由编辑、事务、提案和撤销都作用于当前页面引擎，并更新它的视口。

其他操作：`capture` 返回原生 PNG 工具内容，可用 options.view 调整镜头；`export` 使用已有导出选项，返回服务 exports/ 下的文件；`save` 返回不可变版本回执。截图携带几何载入／失败标记，区块载入时可能是不完整画面。独立 Lite 保留页面 API，不启动此后端连接。

观察等待结束不代表任务停止：用同一 jobId 调用 `designer_job`，不要盲目重复不确定的写入。关闭连接停止接收新任务，已开始的任务仍可能完成。unconfirmed 表示结果未确认，不表示没执行。回执为临时缓存（至多 64 条完成记录、约 10 分钟），不是永久日志；丢失回执或服务重启后，应先读取当前场景再决定后续操作。

旧兼容工具操作独立的 Python 工程，已标记 Legacy；当前页面连接时拒绝这些旧写入，包括旧游戏 apply。当前设计的游戏施工仍使用工作台游戏连接或交付文件。本次验证使用真实 stdio MCP 客户端，不等于已接入某个外部模型服务或完成 Minecraft 实机施工。


共享页面／Worker 协议见 [设计接口说明](lite/DESIGN-API.md)：

```js
const result = await window.CraftStudio.request({
  schema: 'craftstudio-design/1',
  id: 'describe-workspace',
  method: 'workspace.describe',
  params: {}
});
```

此接口属于当前打开的设计器页面，不会自动暴露无需认证的 HTTP 写入口。外部 AI 仍需适配器及自己的工具调用循环；Python／MCP 兼容接口尚未与此协议完全统一。

可选的 [Java 游戏桥接](bridge/README.zh-CN.md)提供 **NeoForge 1.21.1、Forge 1.20.1、Fabric 1.20.1／1.21.1** 独立配置，各自生成对应 JAR；Fabric 还需 Fabric API。本地设计器选择**文件 → 连接 Java 游戏**，可以识别运行版本、读取区域、校验目标方块、施工改动、查看进度、停止和撤销。普通方块经过注册表校验后可跨 DataVersion 施工；原生实体及跨版本方块实体 NBT 仍需原生蓝图／转换流程。

单机写入需要创造模式；专用服务器写入需要管理员明确启用，桥接仍只监听本机。编译验证和真实游戏内验证分别记录。构建产物、安装步骤及版本矩阵见桥接文档。基岩版不在项目范围内。连接面板按桥接能力启用操作：只读/未知写权限保留已支持的读取和检查，禁用建造/世界撤销；令牌或端口变化清除旧连接，施工忙碌时不启新任务。连接界面使用模拟桥接验证，不等同于真实世界施工验证。

重新连接 Java 桥接时可找回正在施工或撤销的任务并查看进度；结束后仍可查询结果，停止按钮关闭。令牌不保存；不支持跨游戏重启恢复施工。

## 开发与构建

浏览器入口负责组合功能模块：文件打开位于 `storage/project-import.js`，页面与 API 的同步位于 `api/page-requests.js`，界面任务状态位于 `ui/task-runner.js`。共享引擎负责场景编辑和校验，页面适配层负责显示及保存状态通知。

草稿状态与自动保存调度集中在 `lite/src/storage/draft-controller.js`，检查点元数据及缓存资源补传集中在 `lite/src/storage/checkpoint-draft.js`。主界面通过回调组合这些服务。并发保存请求共用正在进行的草稿保存，保存期间的新编辑继续保留待保存状态；手动保存成功后取消多余的定时写入。存储错误在持久化边界处理。

源码按职责组织：`backend/` 负责本地文件与 SQLite，`local-engine/` 托管共用 Worker 引擎，`lite/src/` 按 Minecraft 格式、核心状态、建模、草图、地形、素材、选择、渲染、存储和界面分组。`app.js` 与 `worker.js` 保留为浏览器入口，大型静态面板放在对应控制器旁的 `views/` 中。`ui/cad-layout.js` 挂载主界面及模板，`ui/cad-shell.js` 组合设计交互，`materials/material-picker.js` 将选材交给请求它的操作或画笔。

在 `lite` 执行 `npm run format` 或 `npm run format:check`，统一 JavaScript、模板和 CSS 格式。Python 开发使用 `pip install -r requirements-dev.txt`，然后执行 `python -m black backend server.py mcp_server.py tests`；这些是开发工具，不是运行软件的依赖。CI 同时检查格式与行为。



安装 Node.js 22.13 或更高版本，然后执行：

```sh
cd lite
npm install
npm test
npm run build
npm run check:sync
```

在仓库根目录运行后端检查：

```sh
python -m unittest discover -s tests -p "test_*.py"
```

两个版本共用 [`lite/src`](lite/src)。一次构建生成 `lite/dist/CraftStudio-Lite.html`、`web/lite.html` 和 `web/index.html`，同步检查确认三个页面逐字节一致。GitHub `main` 更新并通过检查后，Actions 会重新构建并提交过期的生成文件。这不会自动上传本机修改：本地改动仍需先提交并推送到 GitHub。

下载新版后，重新打开 Lite HTML，或重新启动本地启动器并刷新页面。

## 项目范围、数据与许可

CraftStudio 仍在开发中。目前的限制包括自定义渲染器支持不完整、倾斜放样需要平行截面，以及尚无完整工程仿真或自动配置外部 AI 的能力。

公开构建不包含私人存档、用户蓝图、材质包、截图或数据库。构建默认排除用户数据；`LITE_SOURCE_NBT` 和 `LITE_REFERENCE_HTML` 是个人构建的可选输入，不要发布包含私人数据的输出。本地生成的数据库与日志已纳入忽略规则。

第三方声明见 [THIRD-PARTY](lite/THIRD-PARTY.txt)，第三方代码保留原许可条款。公开发布不包含 Minecraft／Mod 原始游戏贴图。主项目代码目前**尚未单独声明开源许可证**；仓库公开不代表获得无限制复用授权。

接口说明：[设计 API](lite/DESIGN-API.md)。

后端开发可使用 [local-engine](local-engine/README.md) 的共享 Node 宿主、SQLite 检查点与逐笔落盘确认控制器；Python 服务和设计器可按[大场景与本地计算](#大场景与本地计算)中的方式选择启用。
