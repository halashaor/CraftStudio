# CraftStudio Lite

双击 dist/CraftStudio-Lite.html 使用纯前端建筑工作区。代码与主项目说明见 [README](../README.md)，接口见 [DESIGN-API.md](DESIGN-API.md)。

公开版本不嵌入私人数据。场地、原版 / Mod JAR 和材质包由用户主动选择，本地存储由用户所在浏览器管理。方块材质与模型缺失时使用明确的形状预览。

Ctrl+S 保存，Ctrl+O 打开文件，Ctrl+F 搜索素材；左键选择 / 框选，右键旋转，中键平移，F 缩放到选择。支持自建素材类型、别名、收藏和分类库备份。Create 动画使用已适配的原生信息自动预览。

测试默认使用合成数据。特定本地集成测试可以通过 CRAFTSTUDIO_TEST_NBT、CRAFTSTUDIO_TEST_REFERENCE_HTML、CRAFTSTUDIO_TEST_CREATE_JAR 提供对应的个人测试资源；它们不随仓库分发。

## 直接编辑操作

- 选择后用移动 M、复制 C、旋转 R；场景显示拖动手柄和透明预览，位移按格吸附，旋转按 90 度吸附。Enter 确定，Esc 取消，数值可输入相对位移。
- Delete 删除选择，Ctrl+Z 一步撤销；对象成员和几何同步恢复。Shift 可在对象树多选。
- 取材按钮点击场景方块后进入放置；E 从当前鼠标位置取材。Ctrl+滚轮或 [ / ] 调整画笔大小，空格＋左键临时旋转视角。
- 工具栏显示当前素材，点击可换素材；双击工程标题直接改名。精确坐标、阵列等仍保留在更多参数中。

直接编辑手柄使用同版本 Three.js 官方 TransformControls，沿用现有 Three.js MIT 声明。

## 图形、曲线与自动地形

工具栏新增图形 / 曲线、地形入口。直线、矩形、圆、椭圆、圆弧、多边形、长方体及 3–8 控制点贝塞尔曲线可以预览；控制点可用三轴手柄拖动，或从场景拾取。闭合图形可填充。

辅助线和实际方块预览独立显示，预览不修改场景；确认后一次提交，可撤销。辅助线随工程保存但不导出为 Minecraft 方块。曲线按半格映射半砖，上下半部、楼梯上升朝向和拱腹方向分别处理。若同系素材不存在，不伪造 ID，使用主体并提示指定半砖 / 楼梯。

地形支持当前高度上的贴地曲线、自动落地支撑、局部整平、邻域中值平滑、连续坡面和沿设计高度挖填。实际高度来自当前场地数据；保留水面和受阻列，缺数据不造平地。确认前显示挖填与保护冲突。

公开接口增加 construction.prepare / construction.commit。prepare 参数为 {type:'geometry'|'terrain',config,policy}，返回预览 ID、辅助线、数量与冲突；includeMesh:true 可取得网格。commit 参数为 {id,policy,name?}，检查预览基准版本后提交。


## 轮廓建模与剪贴板

“图形 / 曲线”中可选“只保存辅助轮廓”，不会修改任何方块。之后打开“拉伸 / 放样”：
- 拉伸：选择一个闭合轮廓，拖动法线方向的手柄或输入距离；支持反向、双向、空心和切除。
- 放样：Ctrl / Shift 选择多个同一工作平面的闭合截面，按标高自动连接；支持平滑过渡、壁厚与封端。
- 沿路径生成：选择保存的路径，设置竖直矩形截面的宽高；重复和重叠采样由程序合并。
这些是 Minecraft 体素建模操作，体积生成目前使用所选方块，曲线工具单独提供半砖和楼梯的自动落格。不是通用 CAD 实体内核。

Ctrl+C 复制选区，Ctrl+V 进入可拖动和旋转的粘贴预览；当前剪贴板保留在此页面会话中。文本框内保持普通文字复制粘贴。重叠方式可选避开已有、覆盖、仅替换已有；空白不删除目标，保留区和地形保护仍生效。确认一次可撤销，Esc 取消。工具栏复制也记录剪贴板并启动副本移动。“更多”中的阵列和镜像支持批量重复构件。


## 设计工具

工具栏“排列 / 编辑”根据所选操作只显示相关参数：
- Shift 选择多个对象后对齐或等距分布；保留各对象的方块成员。中心和间距最终吸附到整数方块。
- 直线、路径、环形阵列及 X / Z 镜像；沿路径的方块朝向按 90° 吸附。目标重叠默认拒绝，可明确选择覆盖；场地保护仍有效。
- 闭合轮廓向内 / 外偏移，可只保存新的辅助轮廓。复杂凹轮廓可能自交，需要检查预览。
- 边界推拉复制端面方块或缩短选择，保留其他细节位置；包含方块实体的端面不隐式复制设备。
- 布尔合并、相减和求交按实际方块格占用计算；不进行半砖/楼梯的连续实体求交。
- 关联实例创建、从主实例同步、解除关联；同步是用户确认的操作，不是自动跨对象改动。
- 对已有体积建模特征修改拉伸距离、空心和壁厚，预览后替换并可撤销；不是全局 CAD 特征依赖求解器。
- 尺寸、正下方无方块标记、原场地改动、材料和施工分层表。CSV 可直接打开；悬空检查不模拟力学。
- 只看选择、恢复显示和施工层剖切仅改变视图，不删除方块。

“图形 / 曲线”的“工作平面、吸附与尺寸约束”支持整格/半格/自由几何、端点/中心吸附、平面锁定、水平/竖直/平行/垂直直线以及四点贝塞尔对称。直线长度、矩形宽高、圆直径与椭圆宽高可直接输入。最终落块仍使用 MC 方块格及所选半砖/楼梯状态。
