交互设计规格 v1 · 2026-10-05 · 设计目标，尚未完整实现

让人围绕建筑设计，
让程序处理几何、重复与落格。

CraftStudio 面向 Minecraft 建筑审美设计。真实场地是设计依据，用户直接看 3D 场景；草图、参数建模、逐块编辑和 AI 自由建造可以混合使用。本文约定后续实现与验收标准，不代表当前版本已经达到这些标准。

核心原则：稳定的视口与面板位置；从对象和选择出发；先表达设计意图，再生成方块；拖动必须即时反馈；输入与结果保持可理解的关联；一次操作一次撤销。

本轮已实现 · 2026-10-05

主界面采用固定工具列、中央视口、右侧场景集合和上下文参数区，素材与构件在底部展开。图形、拉伸、地形、变换参数均停靠显示。拖动控制点时逐帧显示形状与轻量方块预览，后台只校准最新参数；确认后才修改场景，支持一次撤销。支持轮廓定位和专注视图。草图默认保存辅助线，由场景点击确定起终点；同一平面上首尾相接、没有分叉的独立线段会自动识别成拉伸截面。闭合轮廓支持任意方向的共面截面，自动沿截面法线拉伸；支持反向、双向、空心与切除。倾斜平面上的平行截面可放样；非共面轮廓会报错，不自动压平。左键选择和框选、右键旋转、中键平移；保存辅助线保持相机位置。复杂地形依赖与大体积以即时轮廓配合后台精确结果。

其余章节仍是完整设计目标；完整特征依赖树、任意区域拆分等尚未在本轮实现。已验证 1366×768 布局、持续拖动、素材架、辅助轮廓到拉伸、确认与撤销。

后续研究与实施按 持续设计路线图 推进，包含一手参考、现状证据、阶段优先级和完整工作流验收。本文是交互目标规格，不是已完成功能清单。

1. 借鉴什么，以及怎样适配

成熟设计模式CraftStudio 的采用方式适配边界
Blender：区域、上下文工具、对象与编辑模式固定视口、对象树、属性区和素材架；改变内容而不移动面板；区分选整件与改内部元素。不引入与建筑设计无关的时间线、骨骼和复杂动画工作区。
AutoCAD：吸附、动态输入、命令预览端点/中心/轴线吸附有标记；拖动时显示尺寸；输入数值与鼠标操作连续衔接。常用操作不依赖命令行；搜索命令是补充入口。
SolidWorks：草图、生成特征、树状依赖保存草图与拉伸/放样/阵列之间的引用；同一属性区编辑参数；依赖失效定位到具体对象。允许未完全约束的草图，保留探索和自由建造，不强迫工程设计程序。
Rhino：输入几何驱动结果；Blender：关联对象数据修改源轮廓可预览关联结果；普通副本和关联实例清楚区分。大改轮廓后局部细节可能失去定位，必须显式显示，不能假装能无损重建任意手改。

2. 人的设计路线

观察真实场地→定位与测量→画轮廓 / 放构件→生成和调整体量→组织重复结构→细节与材质→检查与导出

这是推荐路线，不是必须按顺序完成的向导。用户可以从一条辅助线、一栋已有建筑、一块方块或 AI 提案开始。保存、撤销和场景导航始终可用。

  1. 观察现场：打开后立即定位选区。看道路、河岸、高差、旧建筑和地下空间。测量、剖切和隐藏植被帮助观察；原始场地可见但默认不可编辑。
  2. 定布局：放体块、画平面轮廓和轴线，调整宽高、朝向及入口位置。材料可使用占位预设，避免早期陷入挑材质。
  3. 塑造形体：拉伸、偏移、推拉、放样、开洞。选择对象后给出适用操作，不要求先找一个复杂的全功能面板。
  4. 重复与细节：一个窗户或柱子做好后再阵列、镜像或生成关联实例；随后逐块补局部装饰。
  5. 校核与施工：检查实际方块、楼梯朝向、入口衔接、碰撞、土方与分层材料；导出当前版本。

4. 先定义对象，再定义工具

对象含义与操作
原始场地 / 保留区存档读取的基准数据，保留世界原点与文件来源。可显示、测量、作为吸附参照；写入需明确切换到场地编辑。
参考几何轴线、工作平面、尺寸标注、定位点。可以锁定或隐藏，不生成方块、不计入材料。
草图直线、折线、闭合区域、圆弧、贝塞尔曲线以及约束。开放路径和闭合截面有明确标识。
生成对象保存输入草图、参数、材料规则与结果。例如墙体、平台、拱券、屋顶、阵列。编辑生成参数可重新预览。
自由方块对象逐块或笔刷创作的对象，可以组合、复制、换材质，不要求存在上游草图。
构件与实例独立副本有独立内容；关联实例共享构件定义但各自保留位置和朝向。实例级材质覆盖与几何解除关联分别处理。
局部细节在生成对象上手动补的装饰或开洞。保存为独立对象或带定位依据的局部改动，避免一次重建覆盖手工工作。

用户看到建筑对象和生成关系。内部同时保留设计几何、Minecraft 方块实现、原始场地和施工差异。连续曲面好看不等于实际楼梯、半砖与地形可以照建。

5. 草图 → 建筑是主流程

  1. 选工作平面：地面、已有墙面、指定标高、命名参考平面或自由 3D 路径。固定平面与贴地路径明确区分。平面来源始终可见。
  2. 画草图：直接点取、拖拉、输入尺寸。线段显示橡皮筋预览；矩形拖动第二角；曲线控制点和切线柄分工明确。点靠近起点时出现“闭合”标记。
  3. 整理草图：延长、修剪、连接、断开、闭合、偏移；端点/中心/切线吸附与对齐参照可切换。未闭合或自交的位置在视口标出。
  4. 结束草图：命名并保留草图，不自动放置方块。也可直接启动生成命令，以当前合法草图作为输入。
  5. 生成：开放路径对应墙/梁/道路/沿线构件；闭合区域对应平台/围墙/拉伸；多个截面对应放样；路径加截面对应沿路径生成。
  6. 检查并确认：辅助几何、生成预览、最终方块分别可见。厚度、高度、间距等就地调整，材料从素材架选择。
  7. 继续修改：树中选择结果，可定位源草图。改草图时预览所有受影响结果，确认作为一次事务。

一条走向曲线可以同时驱动平台边缘、柱阵列和路灯。草图默认保留；使用引用，不靠复制一份看不见的轮廓维持生成关系。

实例：沿山坡做柱廊

在真实场地上确定平台标高 → 绘制走向曲线 → 偏移出平台宽度 → 预览平台和支撑 → 沿同一条曲线布置柱子 → 在柱顶标高生成梁和屋檐 → 调整曲线观察整体变化 → 查看楼梯、地基与入口衔接。用户主要调整走向、宽度、标高和节奏，程序处理重复方块。

6. 统一选择与命令规则

情形规则
对象模式默认选择整栋建筑或构件。选中与激活分别显示：多选时最后激活的对象可作为对齐参照，属性区显示数量和可共同修改的属性。
草图编辑优先选择草图的点、线段、曲线柄和区域；不被其生成方块抢走点击。退出后恢复对象选择。
方块编辑只在当前对象或明确区域中选择、刷画；原地形保持参照。进入时清楚标出编辑范围。
重叠目标提供候选循环或小型选择菜单；不能靠反复点击猜目标。透视选择、穿透框选由显式开关控制。
吸附吸附前显示目标、类型和位置。绘图几何可自由精度，落块使用整数格及真实方块状态；半格辅助几何不等于任意方块都可放半格。
拖动操作移动手柄、旋转手柄和笔刷的直接拖动：实时预览，松手提交一次操作。键盘启动的移动/旋转：点击或 Enter 提交。每种启动方式的完成提示固定显示；Esc 取消未提交状态。
多步骤生成新建拉伸、放样和阵列等多步骤操作：选输入 → 调参数 → 预览 → Enter/确认提交。此时松手只结束参数拖动，不等于创建完成。Esc 取消本次操作；不能顺便清空选区或关闭其他界面。
连续绘制点选建立连续路径；Enter 结束当前路径；下一次点击开始新路径。约定每条路径的撤销粒度，Backspace 回退最后一个未确认点。
精确输入操作中直接输入距离，X/Y/Z 限轴，Tab 切换当前命令可编辑尺寸；文本框获得焦点时，字母快捷键不触发建模命令。
观察场景观察与编辑输入分开，导航期间不中断操作预览。默认采用 Blender 导航：中键旋转，Shift+中键平移，滚轮缩放；已有用户保留旧配置，并提供明确的键位预设。

菜单、工具按钮、快捷键和右键菜单应调用同一个命令。F3 搜索作为熟练用户入口；常用操作仍能从可见工具发现。提示说明动作和快捷键，不显示内部对象 ID 或方块状态 JSON。

7. 跟手是硬要求

  • 鼠标移动这一帧就更新手柄、轮廓和尺寸；不能等停止移动后才显示。
  • 小规模几何与方块预览持续更新；大模型先显示轻量形体，后台更新实际方块。预览状态明确区分“形状预览 / 方块已校准”。
  • 后台最多一个正在计算的任务和一个可替换的最新请求。旧结果不能覆盖新位置，也不能积累几十次落后计算。
  • 拖动期间复用网格与缓冲区；只更新受影响对象或区块，不重建整片地形，不重建整个参数表单。
  • 锁定平面时不显示该平面法线方向的无效拖动轴；吸附与约束立即反映在手柄和尺寸中。
  • 确认只提交与当前参数、当前场景修订一致的结果。仍在校准时可排队确认最新结果；Esc 仍能取消。
  • 导入等真正阻塞的任务显示进度与取消；日常拖动不能用全屏转圈遮罩。

验收目标，不是当前实测承诺：普通场景拖动的输入到可见反馈 P95 ≤ 50 ms，常用小对象方块预览目标 ≤ 100 ms；大场地至少维持持续的轻量反馈。应记录场景规模、显示设备与渲染环境，不能把软件渲染机器的单次数据当通用保证。

8. 关联更新与自由手改

  • 普通复制默认独立；“关联副本”是显式动作。实例位置、朝向独立；修改构件定义时所有实例参与预览，确认后一起更新。
  • “编辑生成参数”始终保留源草图和生成关系；“逐块细修”进入局部覆盖；“转为自由方块”显式解除生成关系。
  • 细节定位优先保存对象局部坐标、曲线参数或生成面上的定位依据。源轮廓大改使定位失效时，保留细节并标记待定位，不静默删除或移动到错误位置。
  • 删除被引用草图时，属性区显示受影响对象，可选择保留结果并解除关联，或连同派生结果删除。两种操作都可撤销。
  • 依赖图禁止循环引用；失效节点有具体原因，其他对象仍可编辑。重建只影响依赖链，不要求整座建筑从头计算。
  • 显示隐藏、编辑锁定、暂停生成与排除导出是不同状态。默认隐藏仅改变可见性，不改变导出内容。

9. Minecraft 特有的设计层

  • 实际形态：体积与曲线方块化使用合法的全方块、半砖和楼梯状态；考虑朝向、上下半部与连接规则。实现不足时显示近似程度。
  • 材料角色：素材组可定义主体、半砖、楼梯、边缘、支撑。换风格时替换组，不让用户分别输入 ID。缺少对应形态时显示缺项并允许指定替代物。
  • 地形：自由标高、贴地、支撑和挖填是明确可选策略；默认不改河岸或旧建筑。未知区域不推测成平地。辅助线和建筑可以使用同一地形参照。
  • Create：装置按真实方块与已有结构数据预览运动；普通建筑工作区不出现单独动画编辑入口。保留原 NBT 与未知字段。
  • 输出：草图与设计关系留在工程文件。NBT/蓝图输出实际方块与状态；施工差异区分新增、替换、拆除以及 structure_void 跳过语义。

10. AI 与人使用同一底座

AI 可创建/修改草图、设置生成参数、组织实例、提交任意方块操作、读取真实地形、检查差异和获取视角。辅助生成器始终可选。每次提案带输入引用、参数、影响范围与场景修订；在人和 AI 的界面中使用同一预览、冲突检查、提交与撤销模型。

AI 不需要驱动几十个界面按钮。用户可以接着修改 AI 创建的草图、生成对象或自由方块；AI 也能读懂用户已建立的结构关系。状态读取必须区分原始场地、已提交设计、当前预览与仅视图隐藏。

11. 当前代码的差距与改造顺序

现状改造
多个绝对定位浮动面板遮住视口先迁入固定属性区，统一生命周期和滚动范围，再精简工具栏与分组。
曲线预览在每次移动后重置 180 ms 定时器即时视口反馈与后台落格计算分层；最新请求合并，不依赖停止拖动。
拖动中重建控制点输入行更新现有字段和数值，不替换控件，不打断输入焦点。
辅助线主要作为生成后的记录升级为可选择、可命名、可编辑的草图对象，并维护输入引用。
生成参数保留不完整，关联更新仍靠独立命令统一生成特征、依赖重建、实例定义和局部覆盖。
功能与状态分散在多个入口以选择上下文组织命令，固定确认/取消、错误定位和上次操作区域。
  1. 第一阶段：固定布局、选择/导航规则、单一操作状态、实时反馈。先把选择→移动→撤销和画轮廓→拉伸走通。
  2. 第二阶段：草图对象、修剪/闭合/偏移、尺寸约束、生成引用与可修改参数。
  3. 第三阶段：关联实例、沿路径构件、局部手改与再生成的兼容，真实地形衔接。
  4. 第四阶段：检查、分层输出和 AI 双向工作流打磨。已有功能按规则迁入，不继续增加平级浮窗。

12. 用完整任务验收

  1. 导入真实场地→定位保留建筑→量出入口高差→锁定参照。
  2. 绘制闭合轮廓→尺寸输入→拖拉伸高度；拖动未结束时画面与尺寸连续变化。
  3. 编辑源轮廓→墙和平台一起预览变化→取消恢复；确认后一次撤销恢复全部关联内容。
  4. 做一个窗户→沿墙阵列→修改数量；比较独立副本与关联实例的行为。
  5. 在生成屋顶上加手工细节→改变屋顶轮廓；可保留定位成功的细节，失效项有明确位置提示。
  6. 沿坡做道路/台阶与支撑→检查半砖楼梯→导出实际方块。不得通过换一座虚构山来让设计成立。
  7. AI 从草图生成建筑→用户继续编辑→保存重开→结构关系、局部手改和 NBT 数据均保留。
  8. 在 1366×768 和 1920×1080 下完成上述任务；常规建模面板不得覆盖中央模型，窄屏通过收起布局应对。
